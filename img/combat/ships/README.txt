== 플레이어 함선 전투 이미지 ==
이 폴더에 PNG 파일을 넣으면 전투 화면에 자동 적용됩니다.

파일명 규칙: {함선카탈로그ID}.png
  예) S01_main.png -> 기본 머스탱 (ID 앞부분 S01)
  예) S02.png      -> 배저 스카우트
  예) S03.png      -> 코요테
  예) S05.png      -> 팔콘 스카우트
  예) M03.png      -> 셔먼 전투함
  예) M05.png      -> 코브라 트레이더
  예) M07.png      -> 헌터
  예) M10.png      -> 어벤저
  예) H01.png      -> 크루세이더
  예) H04.png      -> 드레드노트

이미지 사양:
  - 크기: 200×120px 권장 (소형), 320×200px (중형), 480×300px (대형)
  - 배경: 투명 PNG
  - 방향: 오른쪽을 바라보는 방향 (게임에서 자동으로 적 함선은 좌우반전)

PNG 없을 경우 자동으로 벡터 그래픽(삼각형 함선)으로 대체됩니다.
