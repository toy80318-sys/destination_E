## How to Install

Pick the file that matches your OS, then follow the steps below.

### 🪟 Windows (Windows 10 / 11, 64-bit)
**Two options:**
- **Installer** — `Destination Earth Setup x.x.x.exe` → double-click and follow the wizard (lets you choose the install folder, creates shortcuts).
- **Portable** — `Destination Earth x.x.x.exe` → no installation; just run it from any folder (great for a USB drive).

> ⚠️ **"Windows protected your PC" (SmartScreen)?**
> This is normal for a new indie game that isn't code-signed yet — it does **not** mean the file is unsafe. Click **More info → Run anyway**.

### 🍎 macOS (Intel & Apple Silicon)
Download the right build:
- **Apple Silicon (M1/M2/M3/M4)** → `Destination Earth x.x.x-arm64.dmg`
- **Intel Macs** → `Destination Earth x.x.x.dmg`

Open the `.dmg` and drag **Destination Earth** into your **Applications** folder.

> ⚠️ **"App can't be opened / unidentified developer"?**
> The app isn't notarized yet. **Right-click (or Control-click) the app → Open → Open**, just once. (Or: **System Settings → Privacy & Security → Open Anyway**.) After the first launch it opens normally.

### 🐧 Linux (AppImage)
Download `Destination Earth x.x.x.AppImage`, then either:
- **GUI:** Right-click → **Properties → Permissions → Allow executing file as program**, then double-click.
- **Terminal:**
  ```bash
  chmod +x "Destination Earth x.x.x.AppImage"
  ./"Destination Earth x.x.x.AppImage"
  ```
> If it won't launch, install FUSE: `sudo apt install libfuse2` (Debian/Ubuntu).

### 🎮 On Steam
Just click **Install** — Steam downloads, installs, and updates the game for you automatically. No manual steps needed.

---

## System Requirements
- **OS:** Windows 10/11 (64-bit), macOS (Intel/Apple Silicon), or Linux (x64)
- **Storage:** ~1.5 GB free space
- **Notes:** Desktop-first; runs on Steam Deck via Proton.

## Save Data
Your progress is saved locally and is **kept when you update** to a newer version. Updating or reinstalling does not erase your saves.

## Updating
- **itch.io / direct download:** download the latest build and run/reinstall it — your saves carry over.
- **Steam:** updates apply automatically.

## 설치 방법

본인 OS에 맞는 파일을 받은 뒤 아래 절차를 따르세요.

### 🪟 Windows (Windows 10 / 11, 64비트)
**두 가지 방식:**
- **설치본** — `Destination Earth Setup x.x.x.exe` → 더블클릭 후 설치 마법사를 따라 진행(설치 폴더 선택·바로가기 생성 가능).
- **포터블(무설치)** — `Destination Earth x.x.x.exe` → 설치 없이 아무 폴더에서나 바로 실행(USB에 담아 쓰기 좋음).

> ⚠️ **"Windows의 PC 보호"(SmartScreen) 경고가 뜬다면?**
> 아직 코드 서명을 하지 않은 신생 인디 게임에서는 흔한 경고로, 파일이 위험하다는 뜻이 **아닙니다**. **추가 정보 → 실행**을 누르세요.

### 🍎 macOS (인텔 & 애플실리콘)
맞는 빌드를 받으세요:
- **애플실리콘(M1/M2/M3/M4)** → `Destination Earth x.x.x-arm64.dmg`
- **인텔 맥** → `Destination Earth x.x.x.dmg`

`.dmg`를 열고 **Destination Earth**를 **응용 프로그램(Applications)** 폴더로 드래그하세요.

> ⚠️ **"확인되지 않은 개발자 / 앱을 열 수 없음" 메시지가 뜬다면?**
> 아직 공증(notarization)을 받지 않은 앱입니다. 앱을 **우클릭(또는 Control+클릭) → 열기 → 열기**를 한 번만 해주세요. (또는 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**.) 첫 실행 이후엔 평소처럼 열립니다.

### 🐧 Linux (AppImage)
`Destination Earth x.x.x.AppImage`를 받은 뒤 둘 중 하나:
- **GUI:** 우클릭 → **속성 → 권한 → 프로그램으로 실행 허용** 체크 후 더블클릭.
- **터미널:**
  ```bash
  chmod +x "Destination Earth x.x.x.AppImage"
  ./"Destination Earth x.x.x.AppImage"
  ```
> 실행이 안 되면 FUSE를 설치하세요: `sudo apt install libfuse2` (데비안/우분투).

### 🎮 Steam에서는
**설치** 버튼만 누르면 됩니다 — Steam이 다운로드·설치·업데이트를 자동으로 처리합니다. 수동 작업이 필요 없습니다.

## 시스템 요구 사양
- **OS:** Windows 10/11(64비트), macOS(인텔/애플실리콘), Linux(x64)
- **저장 공간:** 약 1.5 GB 여유 공간
- **참고:** 데스크톱 우선. Steam Deck은 Proton으로 구동.

## 세이브 데이터
진행 상황은 로컬에 저장되며, 새 버전으로 **업데이트해도 그대로 유지**됩니다. 업데이트·재설치로 세이브가 지워지지 않습니다.

## 업데이트 방법
- **itch.io / 직접 다운로드:** 최신 빌드를 받아 실행(재설치)하면 됩니다 — 세이브는 그대로 이어집니다.
- **Steam:** 자동으로 업데이트됩니다.
