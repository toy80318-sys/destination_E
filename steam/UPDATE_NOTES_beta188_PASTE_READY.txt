================================================================
 DESTINATION EARTH — MAJOR UPDATE (v1.0.0-beta.188) — ENGLISH
================================================================
 ※ Plain text — paste directly into your store page / devlog. No markdown.


This build rolls up 146 versions of work since the previous release (beta.42).
Story, combat, fleet, balance, and UI have all changed significantly.
Grab the new build and dive in!


■ STORY & SCENARIO — the biggest change

 • First-encounter cutscenes for all 8 Legendary Heroes (Yi Sun-sin, Jang
   Yeong-sil, Gwanggaeto the Great, Gagarin, Nelson, Einstein, Tesla, Marco Polo).
 • Main scenario for Phases 1–6 completed — the full story from departure through
   the Void Rift to the final ending, with many new cutscenes.
 • Scenario quests appear instantly the moment you arrive at a planet.
 • Cutscenes 1–9 unlock in sequence; replay any past cutscene anytime.
 • Cleaner writing — 448 internal codes replaced with real planet/item names,
   duplicate and typo lines cleaned up, 59 English cutscenes localized.
 • Main hub quest badge — an at-a-glance counter for the current planet's quests.

■ COMBAT

 • Ship role (specialization) system — 51 ships now have Attack / Defense /
   Transport / Versatile roles for deeper tactics.
 • Loot scales with Reputation — higher reputation means more spoils (about 10 up
   to 100 items).
 • Combat stability — fixed the "battle won't start after the message" bug and
   other entry errors with multiple safety nets.
 • No fleeing mid-battle — you can no longer jump to another planet during combat.
 • More varied pirate encounters with a dedicated character-image pool.

■ FLEET & SHIPYARD

 • HD ship art — all 69 ships unified at 1024×1024 high resolution.
 • Max 8 of the same ship — a cap for fleet diversity, with guidance from Baekgu.
 • Major shipyard UI overhaul — larger ship images, vertical layouts, no cut-off
   text.
 • Codex parts guide — real effects of Laser, Missile, Shield, Armor, Engine, and
   Special Cargo summarized in the Codex.

■ BALANCE

 • Toll-spike bug fixed — tolls are now clamped to a sensible range.
 • Capture rate reduced by 50%.
 • Earth Resistance ships buffed (F06 small/medium/large stats x1.2).
 • Void Energy (VE) inflation eased.

■ UI / UX & QUALITY OF LIFE

 • Reward popups now show real ship / part / blueprint art.
 • Added a main-menu Quit button, refreshed app icon, HUD credit icon, and more.
 • Removed non-functional cloud/email/feedback and duplicate settings buttons.
 • Korean / English text pass.

■ BUG FIXES & STABILITY

 • [Important] Hero quest reward not granted — fixed. (A critical bug where an
   already-recruited hero's quest rewards vanished.)
 • Cutscenes/quests now reliably appear on game start and planet arrival.
 • Resolved cutscene race conditions and several memory leaks.

■ UNDER THE HOOD

 • Split the large single code file into feature modules for stability.
 • Versioning automation + Windows / macOS / Linux three-OS build pipeline.


Supported platforms: Windows · macOS (Intel / Apple Silicon) · Linux
Thanks for playing — feedback is always welcome!


SHORT VERSION (for store / social posts):
Destination Earth's big update is here! First-encounter cutscenes for all 8
legendary heroes and the complete Phase 1–6 main scenario, a combat overhaul with
ship roles and reputation-based loot, HD ship art and a reworked shipyard UI,
toll/balance tuning, and major stabilization including the hero-quest reward fix —
146 versions of changes in one drop. (Windows · macOS · Linux)

■ 스토리 & 시나리오 — 가장 큰 변화

 • 8인 전설 영웅 첫만남 컷씬 추가 (이순신·장영실·광개토대왕·가가린·넬슨·아인슈타인·
   테슬라·마르코 폴로).
 • 페이즈 1~6 메인 시나리오 완성 — 출발부터 보이드 균열, 최종 엔딩까지 + 컷씬 다수.
 • 행성에 도착하면 시나리오·백구 NPC 퀘스트가 즉시 등장.
 • 컷씬 1~9 순차 해금 — 지난 컷씬을 언제든 다시 시청.
 • 대사 정리 — 내부 코드 448곳을 실제 행성·아이템 이름으로 교체, 중복·오타 정리,
   영어 컷씬 59종 번역.
 • 메인 허브 퀘스트 배지 — 현재 행성 퀘스트를 한눈에.

■ 전투 시스템

 • 함선 역할(특성화) 시스템 — 51척에 공격·방어·수송·만능 역할 부여로 전술 다양성 강화.
 • 전리품이 명성에 비례 — 명성이 높을수록 획득량 증가(약 10개에서 최대 100개).
 • 전투 안정성 강화 — "메시지 후 전투가 시작되지 않던" 버그 등 진입 오류 다중 안전망 해결.
 • 전투 중 행성 이동 차단.
 • 해적 조우 시 전용 인물 이미지 풀로 시각적 변주.

■ 함대 & 정비소

 • HD 함선 이미지 — 69종 함선을 1024×1024 고해상도로 통일.
 • 같은 함선 최대 8대 한도 — 함대 다양성을 위한 제한 + 백구의 안내.
 • 정비소 UI 대대적 개편 — 함선 이미지 확대·세로 배치·텍스트 잘림 방지.
 • 도감 파츠 가이드 — 레이저·미사일·실드·장갑·엔진·특수창고 6종의 실제 효과 정리.

■ 밸런스 조정

 • 통행료 폭증 버그 수정 — 합리적 범위로 고정.
 • 나포 확률 50% 감소.
 • 지구저항군 함선 강화 (F06 소·중·대형 능력치 1.2배).
 • 보이드 에너지(VE) 인플레이션 완화.

■ UI / UX & 편의

 • 보상 팝업에 실제 함선·파츠·설계도 이미지 표시.
 • 메인 메뉴 종료 버튼, 앱 아이콘 신버전, HUD 크레딧 아이콘 등 정리.
 • 작동하지 않던 클라우드/이메일/피드백·중복 설정 버튼 제거.
 • 한국어/영어 텍스트 재정비.

■ 버그 수정 & 안정성

 • [중요] 영웅 퀘스트 보상 미지급 수정 — 이미 영입한 영웅의 퀘스트 보상이 사라지던
   치명적 버그 해결.
 • 게임 시작·행성 도착 시 컷씬/퀘스트 즉시 노출 보장.
 • 컷씬 레이스 컨디션, 메모리 누수 다수 정리.

■ 내부 개선

 • 거대한 단일 코드 파일을 기능별 모듈로 분할해 안정성 향상.
 • 버전 자동화 + Windows·macOS·Linux 3-OS 자동 빌드 파이프라인.
