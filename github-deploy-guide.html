🔑 PAT 발급 (이미 발급하셨다면 스킵)

1. https://github.com/settings/tokens/new 접속
2. 설정:
  • Note: Destination Earth CLI
  • Expiration: 90 days (권장)
  • Scopes: ✅ repo (전체 체크)
3. Generate token → 표시된 ghp_... 토큰 즉시 복사 (다시 안 보임)
