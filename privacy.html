3. 제3자 제공·처리 위탁

클라우드 세이브·인증은 Google Firebase(Authentication, Cloud Firestore)를 통해 처리됩니다. 해당 데이터 처리는 Google 개인정보처리방침을 따릅니다. 이 외 제3자에게 개인정보를 판매·공유하지 않습니다.

4. 보관 기간 및 파기

클라우드 세이브 데이터는 이용자가 게임 내에서 삭제하거나 파기를 요청할 때까지 보관되며, 요청 시 지체 없이 삭제합니다. 로컬 데이터는 이용자가 기기에서 직접 삭제할 수 있습니다(설정 → 데이터 삭제).

5. 이용자 권리 (GDPR/CCPA 등)

  • 본인 정보 열람·정정·삭제 요청
  • 클라우드 세이브 삭제: 게임 내 삭제 기능 또는 아래 연락처로 요청
  • 처리 동의 철회(클라우드 로그인 해제)

6. 아동 보호

본 게임은 만 12세 미만 아동을 대상으로 하지 않으며, 실행 시 연령 확인 게이트를 제공합니다. 만 12세 미만으로부터 고의로 개인정보를 수집하지 않습니다.

7. 보안

모든 데이터는 HTTPS 암호화 전송되며 Google Firebase 인프라에 저장됩니다.
