## 1. 프로젝트 개요

**엘리베이터 피치**
지구가 파산하고 100년이 흐른 미래, 냉동 수면에서 깨어난 사령관이 AI 진돗개 **백구**와 함께 단 한 척의 함선으로 은하를 횡단한다. 24개 이상의 행성을 순회하며 무역으로 자본을 쌓고, 함대를 키우고, 역사 속 전설 8인을 영웅으로 영입해, 치크스 제국과 공허(보이드)의 위협을 뚫고 **지구로 귀환**하는 빅 픽처 스페이스 RPG.

**한 줄 정의:** 24+개 행성을 순회하며 함선·영웅을 모아 지구로 귀환하는 싱글플레이 스페이스 RPG.

**장르:** SF 우주 RPG · 무역/경제 시뮬레이션 · 턴제 함대 전투 · 로그라이트 진행
**대상:** 12세 이상 전체 이용가 (PC 게이머, 스페이스 RPG·무역 시뮬 팬)
**언어:** 한국어 / 영어 (i18n 이중 지원, 런타임 전환)

## 2. 핵심 가치 (Core Pillars)

1. **횡단의 여정** — 고정 시드 은하를 링 단위로 한 행성씩 개척하며 지구로 나아가는 진행감.
2. **함대 구축** — 59종 함선과 6 카테고리 파츠로 나만의 함대를 조립·강화.
3. **전설의 영입** — 역사 속 8인(이순신·테슬라·아인슈타인 등)을 영웅으로 모으는 수집의 쾌감.
4. **무역과 경제** — 행성 간 가격차(ΔR 마진)를 읽어 자본을 불리는 경제 루프.
5. **서사적 몰입** — 6개 페이즈에 걸친 컷신 드라마와 숨겨진 이휘소 박사 서사.

## 3. 기술 스택 & 아키텍처 (현행)

| 구분 | 기술 | 비고 |
|---|---|---|
| 클라이언트 | **바닐라 HTML5 + CSS3 + JavaScript** | 프레임워크 없음. 전투/스타맵은 **Canvas 2D API** 직접 렌더 |
| 데스크톱 패키징 | **Electron 33** | `electron/main.js` 셸 (창 상태·환경설정·autoUpdater·Steam 빌드 감지) |
| 빌드 | **electron-builder 25** | Win(nsis+portable), mac(dmg), linux(AppImage) |
| 로컬 저장 | **localStorage** | 게임 진행 세이브 (Electron 내부 partition) |
| 클라우드 세이브 | **Firebase** (Auth 익명 + Firestore) | 선택적 동기화. `js/cloudsave.js` |
| 웹 호스팅 | **Firebase Hosting** | itch.io·웹 병행 배포용 |
| i18n | 자체 사전 (`js/data/i18n_dict.js`) | KO/EN 런타임 전환 |

**아키텍처 개요**
- 메인 로직·상태: `game.js` (함선/영웅/행성/전투/경제 상태 및 진행).
- 기능 모듈: `js/modules/` 26종 — 전투(`combat.js`), 정비소(제작·거래·파츠), 주점 가챠, 퀘스트/컷신, 엔딩 크레딧, 도감, 경매 등.
- 데이터: `js/data/` — 행성·영웅·함선·팩션·파츠·퀘스트·i18n.
- 데이터 흐름: 입력 → `game.js` 로직 → 상태 변경 → DOM/Canvas 렌더 + localStorage 저장.

> ⚠️ **미사용(과거 기획 폐기):** Next.js, Phaser 3, Zustand, Supabase, Firebase Realtime DB/Cloud Functions 기반 실시간 서버. 본 게임은 클라이언트 단독 싱글플레이.

## 4. 플랫폼 & 배포

- **타깃:** PC 데스크톱 x64 (Windows 10+) 우선. macOS·Linux(AppImage) 지원. **Steam Deck**은 Windows 빌드 + Proton 호환 경로.
- **배포처:** **Steam (1순위)**, itch.io, Firebase 웹 호스팅 병행.
- **Steam 업로드:** `dist/win-unpacked/` 폴더를 SteamPipe로 depot 업로드. Launch Option `Destination Earth.exe`.
- **autoUpdater:** Steam 빌드(`STEAM_BUILD=1`·`SteamAppId`·`steam_build.flag` 감지) 시 자동 비활성 — Steam 자체 업데이트 사용.
- **Steamworks SDK(도전과제·오버레이·클라우드):** 현재 미연동, 출시 필수 아님. 추후 `steamworks.js`로 추가 가능.

## 5. 세계관 & 메인 서사

**5.1 지구의 파산 — 100년 전**
경제 붕괴와 자원 고갈로 지구는 파산했고, 인류는 성간으로 흩어졌다. 사령관은 100년의 냉동 수면 끝에 깨어난다.

**5.2 이휘소 박사 (숨겨진 서사 핵심)**
물리학자 이휘소 박사가 남긴 마지막 계산이 보이드 균열과 지구 귀환의 열쇠를 쥐고 있다. 게임 전반에 걸쳐 단서로 흩어진 숨겨진 서사 축.

**5.3 보이드 균열의 기원**
양자 이상점 "보이드(Void)"가 은하에 균열을 내고, 치크스 제국이 이를 이용한다. 최종 위협의 근원.

**5.4 사령관의 각성과 백구**
깨어난 사령관 곁에는 AI 기계 진돗개 **백구**가 동료이자 길잡이로 함께한다.

**5.5 3막 서사 구조**
- **1막 — 출발:** 근거리 문명권에서 무역·함대 기반 구축, 백구와 첫 영웅 영입.
- **2막 — 횡단:** 중간 링 개척, 전설 영웅 규합, 치크스 제국과 충돌.
- **3막 — 귀환:** 외곽 링 돌파, 보이드/우르사 메이저 최종전, 지구 해방 엔딩.

## 6. 은하 지도 구조

- **고정 시드 맵** — 동일 시드로 재현 가능한 은하. 6개 **링(ring)** 구조.
- **구성:** **6링 31개 노드** (링1~5 각 5개 + 링6 6개). 이 중 **약 24개가 주요 순회 행성**, 나머지는 보스/특수/히든 노드(보이드 등 4개 특수 플래그).
- **링이 멀수록** 통행료(tax)·적 난이도·보상이 상승. P01 "프록시마 b"가 시작점.
- **성간 안개(Fog of War):** 미개척 링은 가려져 있으며 워프로 단계적 해금.
- **워프 이동 3단계:** 일반(인접 1홉) → 전설 엔진(2홉) → 블링크(무제한 점프, 블랙홀·고리 무시 + 함대 항속 +20%).
- **ΔR 무역 마진:** 행성 간 특산물 가격차로 차익 실현 — 경제 루프의 핵심.

- **경매** — 싱글플레이 로컬 경매 시뮬레이션 (희귀 함선/파츠 입찰).
- **도감(Codex)** — 함선·파츠·영웅 수집 진행도 및 기능 가이드.
- **명예의 전당(HOF)** — 최종 점수/엔딩 기록.
- **New Game+** — 엔딩 후 회차 진행.

## 12. 함선 & 파츠

- **함선:** SHIP_CATALOG **59종** (소형/중형/대형 + 전설 기함 LGD 6종). 이미지 `img/ships/H/` 기준 1024×1024 통일, 함선당 동일 함선 최대 8대 캡.
- **파츠 6 카테고리:** ⚔️ 레이저 · 🚀 미사일 · 🛡️ 실드 · 🛡 장갑 · ⚡ 엔진 · 📦 특수창고. (cat 기준: weapon 18 + armor 18 + engine 7 + shield 7 종 + 특수창고 SC 계열)
  - 레이저: ATT, 매 턴 자동 발사(실드 우선 → HP). 신화급 흡혈.
  - 미사일: 실드 관통 피해.
  - 실드: INT 강도 + maxSH, 매 턴 자가 복구.
  - 장갑: maxHP + DEF, 일부 매 턴 자동 수리/부활.
  - 엔진: TEC + 이동(1홉/2홉/블링크).
  - 특수창고(SC): 화물칸 확장 (함선당 최대 8칸, 합산 최대 80칸).

## 13. RPG 스탯 시스템

핵심 스탯: **STR(전투력) · ATT(공격) · INT(지능/실드) · DEF(방어) · HP(내구)** + **LOY(충성도)**.
함선 스탯은 파츠·영웅 보너스·역할(Role) 배수·강화로 합산. 함선 **역할(특성화) 시스템**으로 스탯별 가중.

## 14. 진행 구조 (스토리 페이즈)

6개 페이즈, 컷신 CH01~CH15+ 체계 (코드 데이터 `js/data/phase1~6_quests.js`).

| 페이즈 | 내용 | 비고 |
|---|---|---|
| Phase 1 | 출발 — 볼프, 첫 각성/영웅 | CH01~CH02 |
| Phase 2 | 칩 해독, 이순신 영입 | CH03~CH04 |
| Phase 3 | 중간 링 개척 | CH05~CH07 |
| Phase 4 | 추격·치크스 충돌 | CH08~CH11 |
| Phase 5 | 거북선 총공격, 보이드 진입 | CH12~CH14 |
| Phase 6 | 총독의 시대, 최종전·엔딩 | CH15~ (FINAL) |

세부 퀘스트/컷신 대사는 `01_GDD/PHASE1~6_QUEST_CARDS.md` 와 코드 데이터가 동기화되어 있다.

- **메인 허브 HUD:** 함대 자산·통행료·시나리오 퀘 카운터 배지(📜/🆕/🐕).
- **컷신:** 좌측 30% 캐릭터 패널 + 우측 70% 대사. 이미지 폴백 체인(H/ → chars-hd → chars → system).
- **반응형:** 모바일 레이아웃 대응(LOD 이미지) — 단, 출시 1순위는 PC.
- **명예의 전당:** 최종 점수 산정·표시.

## 16. 사운드

- **BGM 45곡** — hub·combat·boss·end + 행성별 테마(P01~) (`02_Assets/audio/`). (과거 GDD "미제작" 정정)

## 17. 세이브 / 영속성

- **게임 진행:** 브라우저 `localStorage` (Electron 내부 partition).
- **Electron 환경설정·창 상태:** `app.getPath('userData')` 하위 — 설치 폴더에 쓰지 않아 Steam Cloud 호환.
- **클라우드 세이브:** Firebase 익명 로그인 + Firestore 동기화(선택).
- 세이브 포맷 변경 시 버전 필드/마이그레이션 처리. **출시 후 기존 세이브 보호.**
