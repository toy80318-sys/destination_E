## 🚨 주요 오류 방지 체크포인트

### 기술적 오류
- [ ] **Galaxy Seed 1000 좌표 고정 검증**: 세션 재시작 후에도 행성 위치 동일한지 확인
- [ ] **Zero-Isolation Protocol**: 모든 30개 행성이 최소 1개 항로 보장
- [ ] **블링크 엔진 분리**: generateGalacticPositions()와 generateHyperTracks() 완전 디커플링
- [ ] **전투 공식 클램프**: min/max 값 전체 검증 (데미지 최소 1 보장)
- [ ] **LOY 탈영 패널티**: LOY ≤ 20 엣지 케이스 처리
- [ ] **세이브 암호화**: AES-GCM 256bit 적용 및 복호화 테스트

### 법적 오류
- [ ] **미성년자 게이트**: DOM 레벨 제거 (CSS display:none 불가)
- [ ] **월 한도 서버사이드**: 클라이언트 우회 차단
- [ ] **가차 확률 공시**: 3곳 모두 표시 (12px 폰트 이상)
- [ ] **미성년자 결제 100% 환불**: 보호자 요청 시 즉시 처리

### 경제 오류
- [ ] **인플레이션 캡**: ε=2.15 지수 함수 올바른 적용
- [ ] **에스크로 잠금**: 입찰 시 즉시 차감, 이중 입찰 방지
- [ ] **스나이핑 방지**: 마감 10초 이내 +30초 자동 연장 작동
- [ ] **LOY 탈영 횡령**: LOY 20 미만 시 자금 횡령 이벤트 트리거
