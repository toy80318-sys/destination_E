## 1. 프로젝트 개요

### 1.1 엘리베이터 피치
> "100년 전 치크스 제국에 의해 파산한 지구를 구하기 위해, AI 기계 진돗개 '백구'가 100년간 구축해 놓은 위장 상단을 이어받은 사령관이 전설의 영웅 8인과 150명의 동료를 모집해 우주 무역·부동산·전투를 통해 자본을 축적하고, 지구 궤도를 봉쇄한 행성형 요새 '우르사 메이저'를 격파하는 하드코어 우주 자본주의 RPG"

### 1.2 핵심 게임 가치 (Core Pillars)

| 필러 | 설명 | 레퍼런스 |
|------|------|----------|
| 성간 무역 경제 | 7대 문명권 간 30종 특산물, 거리 배율 ΔR 마진 4~5배 | Galaxy on Fire 2 |
| 하드코어 로그라이크 전투 | 16v16 턴제, 전멸 시 자산 50% 포맷 패널티 | FTL |
| 부동산 타이쿤 | 행성 경매 낙찰, 총독 파견, 턴당 세금 패시브 인컴 | 일곱 개의 별 |
| 한국 정체성 서사 | 이순신·광개토대왕·장영실이 전설 영웅으로 등장 | 오리지널 |
| AI 동반자 백구 | 100년 대기한 기계 진돗개, 위트 있는 독설 브리핑 | 오리지널 |

## 2. 세계관 및 메인 서사

### 2.1 지구의 파산 — 100년 전

100년 전, 우주 중심부의 생체 괴수 제국 **'치크스 제국(Cheeks Empire)'** 이 지구를 습격했다. 치크스는 지구 궤도에 행성형 거대 요새 모함 **'우르사 메이저(Ursa Major — 데스스타)'** 를 영구 주둔시키고, 시공간 왜곡 성간 안개로 태양계를 봉쇄했다. 살아남은 지구 저항군은 차가운 지하 방공호에 격리됐다.

### 2.2 보이드 균열의 기원 — 제네시스 단층 폭탄

치크스의 봉쇄 무기인 **'우르사 메이저 제네시스 단층 포격'** 은 은하계 오각형 격자의 5번째 꼭짓점(황금비 φ=1.618 수렴점)을 정조준해 시공간 자체를 찢었다. 이 부작용으로 은하계 오각형 링 각각의 5번째 꼭짓점에 **4개의 영구 균열(P27~P30)** 이 새겨졌다. 치크스도 이 균열을 닫지 못한다 — 균열은 생체를 거부하고 기계와 수학을 허용하기 때문이다. 이것이 치크스 은하 지배의 유일한 맹점.

### 2.3 사령관의 각성 — 아인슈타인의 계획

표면적 설명: 공간 전송 기술의 연산 왜곡 부작용.  
**진실**: 100년 전 아인슈타인이 P30(제타 레티쿨리 방주)에서 설계한 **역시간 전송 방정식**이 100년 후의 사령관을 링2 P01(프록시마 센타우리 b)로 끌어당겼다. 사령관이 그 시점, 그 장소에서 깨어난 것은 치크스의 실수가 아닌 **인류 최후의 계획**이었다.

### 2.4 백구의 브리핑

눈을 뜬 사령관을 맞이한 것은 AI 기계 진돗개 **백구**다. 백구는 100년간 P01 고철 무덤에서 폐지를 주워 위장 상단 자산 원장을 구축해 놓았다.

> "내가 폐지 주워서 이만큼 상단 세워놨으니, 돈 벌어서 장비 사고 전설의 영웅들 싹 다 징발해서 지구 구하러 가자."

사령관과 백구는 **빅 픽처 스페이스(Big Picture Space)** 라는 독자 지휘 본부를 설립하고 성전을 개시한다.

### 3.5 ΔR 무역 마진 공식

```
ΔR = |R_i - R_j| + 0.1 × min(|θ_i - θ_j|, 360 - |θ_i - θ_j|)
마진율 = ΔR 배율 적용 (최소 4배 ~ 최대 5배)
```

## 4. 7대 문명권 세력

### F01 수퍼비아 문명권 (Superbia)
- **명칭 스타일**: 북아메리카형 (예: 로버트 스미스, 제임스 앤더슨)
- **패시브**: 부품 분해 반환율 +20%, 수리비 15% 할인, TEC +10%
- **시너지**: 함선 3대 이상 → 이동속도 +15%, 소행성 채굴 드랍율 +10%

### F02 아우레우스 금융 문명권 (Aureus)
- **명칭 스타일**: 서유럽형 수인족 (예: 피에르 뒤부아, 디에고 비안키)
- **패시브**: 경매 유찰 페널티 1회 면제, 에스크로 0ms 환불, 세금 수익 +25%
- **시너지**: 아우레우스 총독 → 특산물 매입가 -15%, LOY 방전율 -30%

### F03 메카니카 공학 문명권 (Mechanica)
- **명칭 스타일**: 슬라브 공업형 (예: 드미트리 이바노프, 세르게이 페트로프)
- **패시브**: 인접 시너지 +15% 오버클럭, INT 배리어 최대치 +15%, 매 턴 실드 3% 자동 충전
- **시너지**: 과학자 NPC 2명 이상 → 전체 부품 전력 소모 10% 감소

### F04 크리그 용병 부족 (Krieg)
- **명칭 스타일**: 남아메리카 라틴형 (예: 카를로스 실바, 루이스 마르티네스)
- **패시브**: 나포 확률 flat +15%, 크리티컬 배율 1.8배
- **시너지**: 적 격파마다 편대 전체 실드 10% 흡수 회복

### F05 치크스 생체 제국 (Cheeks Empire) [적대 세력]
- **명칭 스타일**: 아시아 관료형 (예: 왕 웨이, 응우옌 민)
- **패시브**: 은하핵 환경 대미지 100% 면역, 워프 연료 30% 절감, HP +20%
- **시너지**: 치크스 함선 포함 시 적 도주 첫 3턴 100% 차단

### F06 지구 저항군 전선 (Earth Resistance)
- **명칭 스타일**: 한국형 (예: 김철수, 정성호, 한소희)
- **패시브**: 지구 전선 진입 시 DEX +20%, 최종 피해 10% 감쇄, LOY 탈영 패널티 면역
- **시너지**: 이순신 제독 + 한국형 동료 과반수 → LOY 방전 탈영 완전 무력화

### F07 보이드 양자 문명권 (Void Rift Anomaly) [v5.3 재정의]
- **실체**: 문명이 아닌 **차원 균열 이상점** — 차원 반향체(Dimensional Echo)가 서식
- **패시브**: E15 블링크 엔진 해금, 장거리 워프 연료 40% 절감, INT/TEC +10%

## 11. 16v16 전술 전투 시스템

### 11.1 전투 아키텍처

- **엔진**: Phaser 3 WebGL 독점 세션
- **방식**: 스택형 턴제 격돌 (실시간 난투 아님)
- **규모**: 아군 최대 16대 vs 적 최대 16대
- **타임라인**: React HUD 상단 실시간 턴 오더 칩 표시

### 11.2 핵심 공식

**턴 우선순위**
```
T_priority = TEC_base × (1 + Random(0.0, 0.05)) + 제독 스탯 가중치
```

**명중/회피 판정**
```
P_hit(%) = max(5, min(100, 85 + (DEX_attacker - TEC_defender) × 0.5))
```

**치명타 확률**
```
P_critical(%) = max(1, min(50, 5 + (DEX_attacker - TEC_defender) × 0.2 + 무기 크리티컬 버프))
```

**최종 피해 (크리티컬 배율: 일반 1.0, 크리 1.5, 크리그 패시브 1.8)**
```
최종 피해 = max(1, (원시 DEX 대미지 × 크리티컬 배율 - 장갑 정량감쇄) × (1 - 장갑 효율 감소율))
```

### 11.3 나포(Capture) 시스템

선행 조건: 적 INT(실드) = 0 AND HP ≤ 30%
```
P_capture(%) = max(0, min(95, (LOY_commander / 100) × (30 + (DEX_attacker - HP_target) × 0.3) + 드론 버프))
```
- V1 나포 드론: +0%
- V2 나포 드론: +15%
- 마리 퀴리 액티브 스킬: **100% 확정 나포**

### 11.4 전멸 패널티 (Hardcore Format)

기함 HP=0 → **메인 기함 제외 모든 호위함 + 화물 적재 특산물 + 보유 크레딧 50% 영구 삭제**  
→ 가장 가까운 수퍼비아 안전 정거장으로 리스폰

**방주 프로토콜 (예외)**: 아인슈타인 H06 생존 탑승 시 **자산 유실 0%**, 교전 1턴 전 세이브 지점으로 타임점프 부활

  - 월 지출 한도 **70,000원** 서버사이드 하드캡

## 18. 기술 아키텍처

### 18.1 기술 스택

| 구분 | 기술 | 용도 |
|------|------|------|
| 프론트엔드 | Next.js | UI, 허브, 온보딩 (DOM 레이어) |
| 게임 엔진 | Phaser 3 (WebGL) | 전투 세션, 스타맵 |
| 상태 관리 | Zustand | 전역 게임 상태 |
| 백엔드 DB | Supabase | 클라우드 세이브, 경매 서버 |
| 인증 | JWT + HMAC-SHA256 | WebSocket 패킷 검증 |
| 분석 | Firebase + Mixpanel + Sentry | 이벤트 추적, 에러 모니터링 |
| PWA | next-pwa (workbox) | 오프라인 모드 90% 기능 유지 |

### 18.2 세이브 시스템

- **즉시 동기화**: 대량 무역, 경매 낙찰, 가차 실행, 전설 영웅 영입 → AES-GCM 256bit 암호화 패킷 즉시 전송
- **정기 자동 저장**: 60초마다 델타(변경분)만 압축 전송
- **오프라인 백업**: LocalStorage 암호화 저장 → 재접속 시 자동 머지

### 18.3 성능 목표

| 항목 | 목표 |
|------|------|
| LCP (초기 로드) | < 3초 |
| 프레임 레이트 | 60fps (PC) / 30fps (모바일) |
| 오프라인 기능 | 90% (Service Worker) |
| 브라우저 지원 | Chrome 90+, Firefox 88+, Safari 14+ |
