## 결정 1. 이휘소(H09) 효과 컨셉

**배경:** 현재 H09 이휘소는 스킬·도감이 **INT 최상위/실드·보이드 해석("양자 통찰")** 컨셉. 그런데 요청한 효과는 **미사일 공격력 ×2**라 컨셉이 충돌.

**선택지:**
- **(A) 미사일 마스터로 전환** — 스킬을 "방정식 탄도 — 미사일 위력 2배"로 재정의. 도감 설명도 미사일 중심으로 갱신. (이휘소 방정식 미사일 MMB01 서사와 일치 → 자연스러움) ✅ 권장
- **(B) INT 유지 + 미사일 ×2 추가** — 기존 INT/실드 컨셉 유지하면서 미사일 ×2를 부가 효과로. (효과가 다소 과할 수 있음)

→ **선택: ( A / B )**

## 결정 2. 거북선 설계도 단편 퀘스트 확률

**배경:** "퀘스트를 통한 거북선(LGD01_SP)" 설계도 단편 퀘스트의 등장/드롭 확률만 상향(일반 BLUEPRINT_MAP 5%·일반 LGD01은 유지).

**현재:** 5%
**선택지(목표값):**
- (A) 15%
- (B) 20%  ✅ 권장
- (C) 25%
- (D) 기타: ____%

→ **선택: ( A / B / C / D = __% )**

관련 문서: `CLAUDE_CODE_지시_거북선설계도_획득완화.md` 지시 1
