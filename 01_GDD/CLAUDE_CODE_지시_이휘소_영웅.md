## 1) 영입 퀘스트 신설 (현재 "보스 보상 자동 합류" → 정식 퀘스트화)

- 현재 H09는 아이젠클로(P16 페스작센) 격파 보상으로 자동 합류. **정식 영입 퀘스트**로 만들 것.
- 배치: 페이즈4~5 아이젠클로 단조공장(P16) 라인에 `story_quest` 1건 추가. 기존 아이젠클로/페스작센 퀘스트·컷신 흐름을 **재활용**(신규 세계관 창작 최소화).
- 보상: `H09` 영입 + (선택) 이휘소 방정식 미사일 설계도(MMB01) 연계.
- `cutscene_pre`/`cutscene_post`에 합류 컷신 sceneId 연결(아래 5번).
- 연결성: 직전 사건(집행관 격파) 회상 → 합류 → 다음 목표(우르사 보이드) 훅. (CLAUDE_CODE_지시_스토리연결성_강화.md 원칙 적용.)

## 2) 효과 — 미사일 공격력 ×2 ⭐

- 영웅 효과 적용부(`game.js` 영웅 패시브, 예: L4241 `H03 ATT+15%` 인근)에 **H09 보유 시 미사일 무기 대미지 ×2** 추가.
- 적용 지점: `combat.js` 미사일 대미지 산출부. 미사일(`wtype==='missile'`) 대미지에 H09 보유 배수 2.0 곱.
- ⚠️ **정체성 충돌 — Director 확인:** 현재 H09 스킬/로어는 **INT·실드("양자 통찰")**. 요청한 "미사일 ×2"와 컨셉이 다름. 권장: H09 스킬을 **"방정식 탄도 — 미사일 위력 2배"** 로 재정의하고 `hero.H09.sk/stats/char/op`(ko·en) 및 도감 설명을 미사일 마스터로 보강(이휘소 방정식 미사일 MMB01 서사와 일치 → 자연스러움). INT 컨셉 유지+미사일 추가 vs 미사일로 전환 중 택1 → Director 확정.
- 하드코딩 금지: 배수 2.0은 상수로 분리.

## 3) 전설 이상 미사일 VFX 강화 ⭐

- `combat.js` 미사일 살보(L909~)에서 **미사일 희귀도가 전설(legend)·신화(mythic)일 때** 연출 강화:
  - 더 화려한 곡선(더 넓은 베지어 호·트레일 파티클·발광 강화).
  - 폭파 장면 강화(더 큰 폭발 반경·다단 섬광·파편). 일반 미사일과 시각적으로 구분되게.
- 기존 살보 로직(곡선·stagger·sfx) 위에 rarity 분기 추가. 60fps 보존(L802 주석) 범위 내, 과도한 파티클로 성능 저하 없게.
- 발사 수는 기존 규칙 유지(전설·신화 최대 4발). VFX만 강화.
