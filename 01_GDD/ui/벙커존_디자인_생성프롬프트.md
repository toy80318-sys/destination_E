# 벙커존 행성 디펜스 — 새 디자인 생성 프롬프트

> 용도: 미니게임(타워 디펜스) 비주얼 리뉴얼용 AI 이미지 생성 프롬프트.
> 공통 아트 방향: **다크 스페이스 SF + 네온(시안 #36E3FF / 골드 #FFD25A) + 홀로그램 글래스 HUD**.
> 적 세력 색: 치크스=보라(#A66BFF), 크리그=주황/적(#FF6A3D). 거점=지구 저항군(시안/은백).
> ⚠ 게임 에셋은 **투명 배경(알파)** 또는 **크로마키(안 쓰는 단색, 예: 마젠타 #FF00FF)** 로 뽑아 합성.
> 엔진: 2D HTML 캔버스. 정면/측면 뷰, 깔끔한 실루엣, 과한 그레인 금지.
