# Claude Code 지시서 — 벙커존 '행성 디펜스' 미니게임 (타워디펜스)

> 작성: Cowork 검증 세션 (2026-06-18). 코드 적용은 Coder(Claude Code) 권한.
> ⭐ 한/영 정합성 필수 / 신규 모듈 `js/modules/bunker-defense.js`(정적 로드). ✅ 밸런스 권장 수치 전면 반영·확정.

## 1. 진입 / 구조
- 진입: 벙커존(저항군, P22 계열) 화면 **우측 상단** '행성 디펜스' 버튼 → 오버레이.
- 화면: 상단 = 적 함선 강하(치크스·크리그), 하단 = 둥근 행성 지형. 지상에 벙커 + 대공 레이저/미사일 터렛.
- VFX: combat.js 살보/빔/폭발 재사용. 폭죽 `_fireFireworks()`.

## 2. 핵심 수치 (확정)
- **공격력 = 초당 DPS**(사거리 내 적에게 매초 atk 피해).
- **적 화면 체류 = 10초**(8→10초 확정, W3 ×10 점프 완화). 10초 내 격추 못하면 벙커 도달.
- 사거리 = 강하 구역 전체(단순화). 레이저=즉시히트, 미사일=탄속 곡선.

## 3. 웨이브 (적 HP는 기존 수치 그대로)
| 웨이브 | 적 | HP | 등장 | 시간 | 유입DPS |
|---|---|---|---|---|---|
| 1 | 소형 | 100 | 1대/초 | 20초 | 100 |
| 2 | 중형 | 1,000 | 1대/초 | 20초 | 1,000 |
| 3 | 대형 | 10,000 | 1대/초 | 20초 | 10,000(클라이맥스) |
| 4 | 혼합 소50·중35·대15 | 기존값 | **2대/초** | 20초 | ~3,800 |
- 총 80초.

## 4. 경제 (확정)
- **시작 5,000 크레딧** / 최대 32포대.
- 격추 보상: 소형 300 / 중형 1,000 / 대형 5,000.
- 미니게임 내부 전용(본편 미연동), 클리어 시 별도 보상.

## 6. 강화 (확정)
- 공격력 강화마다 ×1.5, **최대 5강화**(×7.59).
- 비용 = 건설가 × 0.5 시작, 강화마다 ×1.3.
- 등급 해금: 누적 강화 2회 시 다음 등급 건설 해금(1~2등급은 시작부터).

## 7. 승리 / 패배 (확정)
- 승리: 4웨이브(80초) 벙커 생존.
- 패배: 적 벙커 도달 → 벙커 HP 감소(적 공격력=기존 수치), **벙커 HP 0 = 패배**. **벙커 HP=1,000.** HUD에 벙커HP·웨이브·타이머 표시.

## 8. 연계 퀘스트 & 보상 (확정)
- **벙커존 방어 퀘스트** 신설(벙커존 수주). **수락 → 미니게임 진행**(강하 경보 인물 멘트로 진입).
- **성공(80초 방어) 보상:** 크레딧 10,000 + 전설 등급 파츠 1(랜덤) + NPC 크루 1명(랜덤) + 중형 함선 1척 + ⭐ **×2 강화 지구저항군 함선**(`EARTH_RESIST_SP`, 능력치 ×2 고정, price:0). ※ 별칭 "데스티네이션 어스를 달성한" ×5와 **중첩 금지**(×2 함선에 ×5 재적용 안 함). 영웅 보상은 스토리 영웅(H01~H09)이 아닌 **NPC 크루 풀**에서.
- **실패(벙커 HP 0):** 보유 함대 중 **가장 약한 함선 1척 강제 나포** + 몰입 메시지 팝업(적장 도발 + 백구 멘트).
  - ✅ **가드(확정): 함대 2척 이상일 때만 최약체 1척 나포. 1척뿐이면 나포하지 않고 보유 크레딧 30% 차감**(주력/유일 함선 보존 → 진행 불가 방지).
- 보상/패널티 수치는 상수 분리. 멘트 i18n ko/en.

## 밸런스 시뮬 결과 (참고)
- 필요 DPS: W1 100 / W2 1,000 / W3 10,000 / W4 ~3,800.
- 자금(전량격추): 시작 5,000 → W1후 11,000 → W2후 31,000 → W3후 131,000.
- W1·W2 클리어 가능, W3(T7=10,000 DPS 1대)는 경계선 → 강하 10초로 여유 확보(확정). 추가 튜닝((i)대형보상 5,000→7,000 (ii)해금 2→1)은 플레이테스트 후 필요 시.
