# Claude Code 지시서 — 컷신·퀘스트 연결성 강화 + 운항기록 동기화

> 작성: Cowork 검증 세션 (2026-06-18). 코드/대본 적용은 Coder(Claude Code) 권한.
> 사용자 요청: 파편화된 컷신·퀘스트가 **다음 컷신/퀘스트와 이어지도록 연결고리** 생성. 각 컷신·퀘스트는 **이전 컷신·퀘스트 언급(회상)부터 시작**해 이어질 것. 현재 연결성 부족 → 연결성 + 다음 행성 안내 방식 개선. **탐색도감 운항기록도 동시 업데이트.** 스토리·대화 연결성/이해도 강화.
>
> ⭐ **한/영 정합성 필수:** 모든 신규/수정 대사·멘트는 `i18n` 한·영 양판(또는 phase 파일의 ko/en 구역) 동일 반영. 적용 후 `node scripts/i18n-parity.js` 0 확인. 영문은 직역 아닌 자연 대사.

## 현재 구조 (확인됨)

- **컷신 대사 데이터:** `js/data/phase1~6_quests.js` 내 `sceneId:[{char,name,color,text}, …]` 블록. 한글 구역 + 영문 구역으로 파일 내 분리(예: phase1 KO ~L468, EN ~L556).
- **퀘스트↔컷신 연결:** 각 퀘스트 객체의 `cutscene_pre`(수주/진입 시) · `cutscene_post`(완료 시) 가 sceneId 참조. (예: `cutscene_pre:'p1_ch01a', cutscene_post:'p1_ch01b'`)
- **행성↔인트로 컷신:** `_intros`/`P01:'p1_ch01a'` 매핑 → `forceReplayScene`.
- **영웅 시나리오 순서:** `story-scenes-pc.js` `SCENARIO_ORDER = ['H08','H04','H01','H05','H02','H03','H06','H07']`, `HERO_PLANET_MAP`(영웅→행성·조건).
- **운항기록(탐색도감):** `js/data/baekgu-diary.js` `BAEKGU_DIARY` = 6장(`"1"~"6"`), 각 `{title, entries:[{t,who,when,where,…}]}`.

**문제:** 컷신/퀘스트가 개별 완결형이라 앞뒤 사건을 서로 언급하지 않음 → 흐름·인과가 끊겨 이해도 저하.

## 연결성 모델 — "회상 → 본문 → 훅" (모든 주요 컷신에 적용)

각 챕터 컷신을 3구간으로:

1. **오프닝 회상(1줄, 인물 대사):** 직전 사건·획득물·결정을 짧게 환기.
   - 예) 백구: "방금 **{이전행성}**에서 **{이전획득물}**을 손에 넣었죠. 그런데 그게 끝이 아니었어요."
2. **본문(기존 대사 유지/보강):** 현재 사건. 인과("그래서/때문에")로 앞과 연결.
3. **클로징 훅(1~2줄, 인물 대사):** 다음 목표 + **다음 행성**을 세계관 멘트로 권유(시스템어 금지).
   - `"{목표/물건}을 얻기 위해 {다음행성}으로 향하자."` / `"{문제/위협}을 해결하려면 {다음행성}으로 가야 한다."`

> 다음 행성 안내·인물 멘트 상세 규칙은 **CLAUDE_CODE_지시_퀘스트_컷신_자동등장.md 지시 2** 와 동일 원칙. 행성명은 반드시 i18n `planet.<ID>.nm` 토큰.

### 적용 예시 (phase1 p1_turtle1 — 설계도 단편 1 직후)

- (회상) 마르코: "방금 그 노인이 건넨 칩 — **거북선 설계도의 첫 조각**이었어."
- (훅) 백구: "나머지 두 조각이 더 있어요. 다음 단서는 **{planet:P06}**(넥서스 프라임)에 — 가가린을 만나러 가죠."

## 퀘스트 체인 연결 (cutscene_pre/post 정합)

- 퀘스트 N 의 `cutscene_post` 마지막 줄 = 다음 목표/행성 훅 → 퀘스트 N+1 의 `cutscene_pre` 첫 줄 = 그 사건 회상으로 받기. (앞 훅과 뒤 회상이 **같은 사건을 가리키게** 정합.)
- `cutscene_pre/post`가 `null`인 핵심 시나리오 퀘스트에는 **연결용 짧은 컷신 또는 인물 멘트 팝업**을 신설(특히 페이즈 경계: phase1→2→…→6, 영웅 영입 사이, 보스 전후).
- 영웅 영입 순서(SCENARIO_ORDER)와 행성 이동이 대사로 자연 연결되는지 점검: H08(우르사 알파)→H04(카스텔룸)→H01(아이젠콕)→… 각 전환에 "다음은 누구를, 어디서" 훅.
- 보스(중간/파이널/히든) 전후 컷신도 직전 사건 회상 + 다음 국면 훅으로 연결(보스팝업→컷신 전환은 CLAUDE_CODE_지시_거북선_보스컷신_메타.md 지시 2 참조).

## 운항기록(탐색도감) 동기화 — `baekgu-diary.js`

- 컷신/퀘스트에 추가한 **회상·훅·다음행성** 내용을 운항기록 6장 엔트리에도 반영 → 로그만 읽어도 사건이 **연속된 항해기**로 이어지게.
- 각 엔트리 끝에 **다음 장으로 넘어가는 한 문장**(다음 목적지·동기)을 추가해 장-간 연결.
- 행성명은 신규 확정명(PLANET_RENAME_APPLY.md) 사용, 코드네임/구지명/메타("행성 N~") 금지 — 기존 잔존 메타는 CLAUDE_CODE_지시_거북선_보스컷신_메타.md 지시 3과 함께 정리.
- 한/영(ko/en) 양판 동일 반영.

## 작업 순서(권장) & 검증

1. 페이즈별로 컷신 목록을 뽑아 **연결 맵**(이전훅↔다음회상) 표 작성 후, 누락 구간에 회상/훅 줄 삽입.
2. `cutscene_pre/post` null 핵심 퀘스트에 연결 컷신/멘트 보강.
3. 운항기록 6장에 회상/훅/다음행성 반영.
4. 검증:
```bash
node --check js/data/phase1_quests.js js/data/phase2_quests.js js/data/phase3_quests.js js/data/phase4_quests.js js/data/phase5_quests.js js/data/phase6_quests.js js/data/baekgu-diary.js
node scripts/i18n-parity.js          # 한/영 정합성 0 확인
# 메타/코드네임 잔존 0 재확인
grep -rnoE "(text|line):'[^']*(행성\s*[0-9]+\s*[~-]|Ring\s*[0-9]|페이즈\s*[0-9])" js/data/phase*_quests.js js/data/baekgu-diary.js
```
5. 인게임 1회 통주행으로 컷신→퀘스트→다음행성→다음컷신 끊김 없음 + 운항기록 연속성 확인 → Director 보고.
