## 적용 원칙 & 검사

- **퀘스트 목표/대사에 "G18 ×1 소비" → "난중일기 영인본 ×1 소비"** 처럼 코드를 실제 이름으로. 수량/기호는 유지.
- "H10 레비아탄 / H12 우르사 파쇄기"처럼 **코드+이름이 같이 있으면 코드만 제거.**
- 행성 P##는 **신규 확정명**으로(슈멜츠·아이젠콕 등).
- **전수 재검사:**
  ```
  grep -rnE "(text|desc|label|ko|en):'[^']*(P[0-9]{2}|G[0-9]{2}|R0[1-8]|LGD[0-9]{2}|H1[0-3])" js/data/phase*_quests.js js/story-scenes-pc.js
  ```
  (H01~H08은 영웅 영입 문맥에서만 — 스킬/판별 코드와 구분)
- 적용 후 `node --check` + 게임에서 퀘스트 목표·컷씬에 코드 노출 0 확인.
