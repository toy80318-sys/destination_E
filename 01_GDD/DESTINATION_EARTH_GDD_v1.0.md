## 1. 게임 개요

### 1.1 엘리베이터 피치 (Elevator Pitch)
> "지구의 위기를 막기 위해 우주를 누비는 한국 청년 영웅과 그의 동반자 백구가 158명의 동료와 함께 8명의 빌런에 맞서 싸우는 우주 RPG 어드벤처"

### 1.2 게임 기본 정보

| 항목 | 내용 |
|------|------|
| 게임 제목 | DESTINATION EARTH (데스티네이션 어스) |
| 장르 | 우주 RPG / 턴제+실시간 혼합 액션 |
| 플랫폼 | 웹브라우저 (HTML5) |
| 플레이 인원 | 1인 (싱글플레이어) |
| 예상 플레이타임 | 메인스토리 20~30시간 |
| 등급 | 전체 이용가 (12세 이상 권장) |
| 개발 도구 | HTML5 + Phaser.js + JavaScript |

### 1.3 게임 컨셉 키워드
- **한국 정체성**: 주인공은 한국 청년, 이휘소 박사(실존 물리학자 오마주) 멘토
- **우주 모험**: 태양계 내 행성들을 무대로 한 광대한 우주 여행
- **동반자 시스템**: 충견 백구와 함께하는 감동적 스토리
- **팀 빌딩**: 158명의 NPC와 8명의 영웅을 모집·육성
- **선택과 결과**: 플레이어의 선택이 스토리와 결말에 영향

### 1.4 USP (Unique Selling Point)
1. 한국 정체성을 담은 SF 우주 영웅 스토리
2. 실존 과학자 이휘소 박사를 오마주한 멘토 캐릭터
3. 개 캐릭터 '백구'와의 유대감 기반 감성 서사
4. 158명 등장인물의 방대한 캐릭터 세계
5. 웹브라우저 기반으로 설치 없이 즉시 플레이 가능

## 2. 세계관 및 스토리

### 2.1 세계관 설정

**배경 연도**: 2157년

인류는 태양계 전역으로 진출했으나, 우주 어딘가에서 발생한 '다크 엔트로피(Dark Entropy)' 현상이 지구를 향해 다가오고 있다. 이 현상은 행성의 에너지를 흡수해 생명체를 멸종시키는 우주적 재앙이다.

UN 우주방위기구 GEDA(Global Earth Defense Agency)는 이 위협에 맞서기 위해 비밀 프로젝트 **"데스티네이션 어스"**를 가동한다 — 지구를 최종 목적지로 삼아, 우주 전역에 흩어진 에너지 코어를 수집하고 빌런들의 계획을 저지하는 임무다.

### 2.2 행성 무대 설정

| # | 행성/구역 | 특징 | 주요 이벤트 |
|---|----------|------|------------|
| 1 | 지구(Earth) | 출발점, 현대+미래 도시 | 프롤로그, 튜토리얼 |
| 2 | 달(Moon) | 저중력, GEDA 기지 | 첫 전투, 영웅 합류 |
| 3 | 화성(Mars) | 사막 식민지, 반란 세력 | 빌런 첫 조우 |
| 4 | 목성 구역(Jupiter Zone) | 거대 가스행성 위성 | 중간 보스 전투 |
| 5 | 토성(Saturn) | 고리 미로, 에너지 코어 | 핵심 퍼즐 구간 |
| 6 | 천왕성(Uranus) | 얼음 행성, 고대 유적 | 이휘소 박사 비밀 |
| 7 | 해왕성(Neptune) | 폭풍 행성, 최종 빌런 기지 | 클라이맥스 전투 |
| 8 | 다크 존(Dark Zone) | 다크 엔트로피 진원지 | 최종 보스 |

### 2.3 메인 스토리 아크

**Act 1 — 각성 (지구 ~ 달)**
주인공 강이준은 우연히 GEDA의 실험 우주선을 발견하고 백구와 함께 탑승하게 된다. 이휘소 박사의 AI 홀로그램이 나타나 임무를 부여한다. 달 기지에서 첫 영웅들과 합류.

**Act 2 — 시련 (화성 ~ 목성)**
화성에서 첫 번째 빌런 '철공 막스'와 조우. 자신이 특별한 에너지 감지 능력을 가진 '에너지 리더'임을 깨닫는다. 팀원 모집과 배신 사건.

**Act 3 — 각성 (토성 ~ 천왕성)**
이휘소 박사의 실제 목적이 밝혀지고, 다크 엔트로피의 진원지 정보를 입수. 백구가 위기에 처하는 감정적 클라이맥스.

**Act 4 — 귀환 (해왕성 ~ 다크 존)**
최종 빌런 '다크 오메가'와의 최후 대결. 158명의 동료와 함께 지구를 구하는 결전.

**엔딩 분기**
- **진 엔딩**: 모든 영웅 생존, 다크 엔트로피 소멸, 지구 귀환
- **노멀 엔딩**: 지구 구출, 일부 희생
- **배드 엔딩**: 지구 일부 피해, 재건 시작

## 3. 등장인물

### 3.1 주인공

**강이준 (Kang Yi-jun)**
- **나이**: 24세
- **직책**: GEDA 신규 에이전트 / 에너지 리더
- **외형**: 한국인 청년, 검은 머리, 파란색 전투복 (GEDA 마크)
- **성격**: 용감하고 정의감 넘침, 때로는 충동적, 동료를 아끼는 따뜻한 마음
- **능력**: 에너지 감지 및 증폭, 전투 스킬, 리더십 오라
- **약점**: 과거 트라우마 (부모님 우주 사고로 실종), 백구에 대한 과보호
- **성장 호**: 미숙한 청년 → 지구를 지키는 영웅

**스탯 기본값**
| HP | MP | ATK | DEF | SPD | INT |
|----|----|----|-----|-----|-----|
| 500 | 300 | 85 | 70 | 90 | 75 |

### 3.2 동반자 — 백구 (Baekgu)

**백구**
- **종**: 진도견 (흰색)
- **특기**: 냄새 추적, 에너지 탐지, 적 경보, 아이템 탐색
- **게임 역할**: 보조 유닛 — 자동 이동, 아이템 탐지, 적 선제 감지
- **스토리 역할**: 주인공의 감정적 지지대, 후반 핵심 스토리 트리거
- **특수 스킬**:
  - 짖기(Bark): 주변 적 기절 1초
  - 냄새 추적(Sniff): 숨겨진 아이템/루트 발견
  - 돌격(Charge): 적에게 돌진, 넉백 효과
  - 빛 구슬(Light Orb): 어두운 구역 조명 (에너지 충전 후)

### 3.3 멘토 — 이휘소 박사

**이휘소 박사 (Dr. Lee Hwi-so)**
- **모티브**: 실존 물리학자 이휘소(Benjamin W. Lee) 오마주
- **형태**: AI 홀로그램 (우주선 내장)
- **역할**: 기술 정보 제공, 스토리 해설, 아이템 연구, 스킬 교육
- **성격**: 온화하고 지혜로움, 유머 감각, 강이준에 대한 부성애
- **비밀**: 실제 이휘소 박사의 의식이 AI에 업로드된 것 (Act 3에서 공개)
- **특수 기능**:
  - 연구 시스템 운영
  - 아이템 업그레이드 가이드
  - 보스 패턴 힌트 제공

## 4. 핵심 게임플레이

### 4.1 게임 흐름

```
[메인 메뉴] → [스토리 선택/계속하기]
      ↓
[우주선 허브 (Hub World)]
  ├── 이휘소 박사 AI 연구실
  ├── 영웅 관리실
  ├── 아이템 창고
  └── 성운 지도 (행성 이동)
      ↓
[행성 탐험]
  ├── 필드 탐색 (이동, 아이템 획득)
  ├── 전투 구간 (실시간 전투)
  ├── 이벤트/대화
  └── 미니게임
      ↓
[보스 전투]
      ↓
[스테이지 클리어 → 보상 → 다음 행성]
```

### 4.2 전투 시스템

**전투 타입**: 실시간 + 턴제 하이브리드

- **실시간 이동**: WASD 또는 방향키 / 모바일 터치 조이스틱
- **공격**: 마우스 클릭 / 탭 or Z키
- **스킬 사용**: 1~4 단축키 / 화면 하단 스킬 버튼
- **파티**: 최대 4명 동시 출전 (주인공 + 영웅 3명)
- **백구**: 자동 AI 보조 (상시 동행)

**전투 순서 (턴 개념 적용 구간)**
- 게이지 바 충전 → 스킬 발동 가능
- 스킬 쿨타임 시스템 적용
- 연속기 (콤보) 시스템: 3연속 공격 시 추가 데미지 1.5배

### 4.3 파티 시스템

- 최대 파티 구성: 4명 (주인공 필수 + 영웅 3명 선택)
- 백구는 별도 슬롯 (항상 동행)
- 시너지 보너스:
  - 한국인 3명 이상: 팀 공격력 +10%
  - 힐러 포함: 전투 후 HP 30% 자동 회복
  - 해커 + 스나이퍼: 정밀 저격 스킬 해방

### 4.4 성장 시스템

**레벨업**
- 경험치 획득 → 레벨업 → 스탯 자동 증가 + 스킬 포인트 지급
- 최대 레벨: 50
- 레벨업 시 스킬 포인트 2점 지급

**스킬 트리**
각 캐릭터별 3갈래 스킬 트리 (공격형 / 방어형 / 서포트형)
- 주인공 스킬 트리: 에너지 블레이드 계열 / 리더십 오라 계열 / 에너지 감지 계열

**장비 시스템**
- 5개 슬롯: 무기, 방어구(장갑), 엔진 모듈, 쉴드 발생기, 특수 아이템
- 장비 등급: 일반(회색) / 고급(녹색) / 희귀(파란색) / 영웅(보라색) / 전설(주황색)

## 5. 게임 시스템

### 5.1 우주선 시스템 (Hub)

우주선 "이준 호 (Yi-Jun)"는 플레이어의 베이스 캠프이다.

**우주선 구역**
- **조종실**: 행성 간 이동, 성운 지도
- **이휘소 박사 연구실**: 아이템 연구/업그레이드, 스킬 교육
- **작전실**: 퀘스트 확인, 팀 편성
- **격납고**: 우주선 업그레이드 (속도/내구력/무기)
- **영웅 구역**: 각 영웅 개인 방 (유대감 대화)
- **백구 공간**: 백구와 상호작용 (아이템 탐지 훈련)

### 5.2 아이템 시스템

| 아이템 종류 | 설명 |
|-----------|------|
| 무기 (Weapons) | 근접/원거리/에너지 계열, 공격력 강화 |
| 쉴드 (Shield) | 방어막 발생기, 피해 흡수 |
| 장갑 (Armor) | 물리/에너지 방어력 증가 |
| 엔진 모듈 (Engine) | 이동속도, 우주선 성능 |
| 소모품 | HP 포션, MP 포션, 부활 아이템 |
| 코어 에너지 (Core Energy) | 스토리 핵심 아이템, 행성별 1개 |
| 설계도 | 이휘소 박사에게 제출 → 신규 장비 제작 |

### 5.3 퀘스트 시스템

**메인 퀘스트**: 각 행성당 3~5개 (총 약 40개)
**서브 퀘스트**: 각 행성당 3~8개 (총 약 60개)
**히든 퀘스트**: 14개 (특별 NPC 연계)
**영웅 개인 스토리 퀘스트**: 영웅 1명당 3개 (총 24개)

### 5.4 상점 시스템

- **행성 상점**: 각 행성 주요 거점에 상인 NPC 위치
- **우주선 자동 판매기**: 기본 소모품 구매
- **이휘소 박사 연구 시스템**: 설계도 + 재료 → 고급 장비 제작

**화폐**: 은하 크레딧 (Galaxy Credits, GC)
- 전투 승리, 퀘스트 완료, 아이템 판매로 획득

### 5.5 세이브 시스템

- 자동 저장: 스테이지 클리어, 체크포인트 도달 시
- 수동 저장: 우주선 내 어디서나 가능
- 세이브 슬롯: 3개

## 11. 게임 밸런스

### 11.1 전투 밸런스 공식

**기본 데미지 계산**
```
데미지 = (공격자 ATK × 스킬 배율) - (방어자 DEF × 0.5)
최소 데미지 = 1 (데미지가 0 이하일 경우)
크리티컬 = 데미지 × 1.5 (크리티컬 확률 = 10% + 레벨 × 0.5%)
```

**레벨 스케일링**
```
스탯 증가 = 기본값 × (1 + 레벨 × 0.08)
적 HP 스케일 = 기본 HP × (1 + 스테이지 × 0.15)
경험치 = 적 레벨 × 10 + 기본 30
```

### 11.2 경제 밸런스

| 스테이지 | 일반 적 드랍 GC | 보스 드랍 GC | 아이템 평균 가격 |
|---------|--------------|------------|--------------|
| 1~2 (지구/달) | 10~50 | 500 | 100~300 |
| 3~4 (화성/소행성대) | 30~100 | 1,500 | 300~800 |
| 5~6 (목성/토성) | 80~200 | 3,000 | 800~2,000 |
| 7~8 (천왕성/해왕성) | 150~400 | 6,000 | 2,000~5,000 |
| 9+ (다크 존) | 300~800 | 15,000 | 5,000~15,000 |

### 11.3 난이도 설정

| 난이도 | 적 HP 배율 | 적 ATK 배율 | 경험치 배율 | 아이템 드랍률 |
|-------|-----------|-----------|-----------|------------|
| 쉬움 | × 0.7 | × 0.7 | × 1.2 | × 1.3 |
| 보통 | × 1.0 | × 1.0 | × 1.0 | × 1.0 |
| 어려움 | × 1.5 | × 1.3 | × 0.9 | × 0.8 |
| 지옥 | × 2.0 | × 1.8 | × 1.5 | × 0.6 |
