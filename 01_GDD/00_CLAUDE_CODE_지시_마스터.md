## A. 공통 규칙 (전 지시서 공통 — 개별 문서에 반복 기재 안 함)

1. **한/영 정합성:** 모든 신규/수정 대사·멘트·라벨·별칭은 `i18n/ko.js`·`i18n/en.js` 양판 동일 키. 적용 후 `node scripts/i18n-parity.js` → 키 일치·누락 0·미번역 0. 영문은 직역 아닌 자연 대사.
2. **멘트는 세계관 1인칭 몰입형:** 시스템어("다음 단계", "행성 N으로", "퀘스트 수락됨") 금지. 백구·이순신·장영실·마르코 등 화자 톤. "{목표}을 얻기 위해 / {문제}를 해결하려면 {행성}으로" 형식.
3. **행성·코드명:** 행성명은 i18n `planet.<ID>.nm` 토큰만 사용. 코드네임(P##/G##/R##/H##/LGD##)·구지명·메타("ACT/페이즈/Ring/행성 N~") 노출 금지.
4. **하드코딩 금지:** 밸런스 수치·효과 배수·확률은 데이터 상수로 분리.
5. **검증 루틴:** 변경 .js마다 `node --check` → i18n-parity → 인게임 1회 → Director 보고. 같은 문제 3회 반복 시 에스컬레이션.

## C. 정정·확정 이력 (중복/오지시 제거 — 아래가 최종)

- 거북선(LGD01_SP): 스펙 변경 없음 = **HP·능력치 ×5, 크기 ×2 현행 유지**. 이미지 `LGD01_SP.png` 보완 **완료**. (초기 ×3·1.5 안은 폐기.)
- 특수 ×5 거북선은 **퀘스트(LGD01_SP) 전용** — 일반 LGD01·BLUEPRINT_MAP과 분리(코드 검증 완료, 변경 불필요).
- 이휘소 효과 = **미사일 마스터 전환(A)** 확정. (INT/실드 컨셉 문구는 미사일 중심으로 교체.)
- 설계도 단편 확률 = **20%(B)** 확정.
- 전투 등장 팝업 **"1회 통합" 폐기 — 기존 흐름 유지.** (개정 확정.)
- 버튼: **전투 시작 버튼만 팝업 우측 하단**으로. **전투 모드 일시정지·도망가기 = 기존 위치 유지**(이동 안 함).
- 효과 중첩: 별칭은 동시 1개만 적용. **×5 별칭은 ×2 보상 특수함선에 재적용 금지**(중첩 시 ×10 방지).
- 보스러시 패배선 48 = **화면 내 동시 적 수**(누적 아님).
