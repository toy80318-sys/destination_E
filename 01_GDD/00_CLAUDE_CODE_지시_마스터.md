## A. 공통 규칙 (전 지시서 공통)
1. **한/영 정합성:** 신규/수정 대사·멘트·라벨·별칭은 i18n ko/en 양판 동일 키. `node scripts/i18n-parity.js` 0 확인. 영문은 자연 대사.
2. **멘트는 세계관 1인칭 몰입형:** 시스템어 금지. "{목표}을 얻기 위해 / {문제}를 해결하려면 {행성}으로" 형식.
3. **행성·코드명:** i18n `planet.<ID>.nm` 토큰만. 코드네임/구지명/메타(ACT·페이즈·Ring·"행성 N~") 노출 금지.
4. **하드코딩 금지:** 밸런스 수치·배수·확률은 상수 분리.
5. **검증 루틴:** 변경 .js마다 `node --check` → i18n-parity → 인게임 1회 → Director 보고.

## C. 정정·확정 이력 (최종)
- 거북선(LGD01_SP): HP·능력치 ×5·크기 ×2 유지, 이미지 보완 완료. (×3·1.5안 폐기)
- 특수 ×5 거북선 = 퀘스트(LGD01_SP) 전용, 일반 LGD01/BLUEPRINT_MAP과 분리.
- 이휘소 = 미사일 마스터(A). 설계도 단편 = 20%(B).
- 등장 팝업 "1회 통합" 폐기 — 기존 유지. 버튼: 전투 시작만 우하단 / 일시정지·도망 기존 위치.
