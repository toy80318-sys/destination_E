# 음성 대본 — 수정 필요 정리 (2026-06-20)

> Cowork STT 정합 검증 결과. 음성이 **녹음되지 않았거나(치크스 이후), 녹음과 대본이 다르거나, 변수/코드/메타가 남아 TTS에 부적합한** 대본만 추렸다.
> ※ 단순 STT 오인식(예: 백구 71 "창고 칸으로 확장"→"상곡한 헛장")은 **클립 위치가 정상**이므로 제외.

---

## 1. 치크스 전위대 이후 — 아직 음성 없음 (생성 필요)

NPC/적 통행료·도발 멘트. 각 1줄. **TTS 전 `₡` → "크레딧"** 으로 바꿔 읽혀야 함.

| num | 인물 | 정리된 대본(읽기용) |
|---|---|---|
| 475 | 치크스 전위대 | 이곳은 치크스 관할 공역. 허가 없는 외래종의 통행은 — 적대 행위로 간주한다. |
| 476 | 불칸 | 그뿐만이 아니다 — 마그마 코어 비축고도 통째로. 당신들이 뭘 만들든, 필요하면 가져가라. |
| 477 | 철갈고리 보그 | 어이 거기 함대. 이 항로는 내 구역이야. 통행료 **크레딧**만 내놓으면 곱게 보내주지. |
| 478 | 밀수왕 카림 | 오, 함선들 좋은데? 흠집 내기 싫으면 **크레딧**만 내. 사업은 사업이니까. |
| 479 | 치크스 군단장 크라쉬 | 인간 주제에 감히 여기까지. 목숨값으로 **크레딧**를 바쳐라. 그럼 오늘은 살려두마. |
| 480 | 현상금 사냥꾼 베일 | 네 목에 걸린 현상금보다 **크레딧**가 싸게 먹히겠지? 자, 선택해. |
| 481 | 약탈자 도르가 | 함선이 아깝지 않냐? **크레딧** 내면 못 본 척 해주마. 거절하면… 후회할걸. |

## 2. etc 그룹 (482~491) — 영문·기호·네이밍 혼재 (정리 필요)

`char_slug = etc`. 한 인물 안에 **여러 화자 대사 + 영문 + ⚠ 시스템 기호**가 뒤섞여 있음. 화자 재배정/언어 통일 결정 필요.

| num | 문제 | 원문 |
|---|---|---|
| 482 | 화자 불명 + 오타("그 로군"→"그 분이로군"?) (476은 불칸으로 변경되어 볼칸 충돌 해소) | 당신들이 저항군과 함께 싸운다는 그 로군. 우리 '스파크'는 크리그 공장 노동자들의 자유 민병대다… |
| 483 | **⚠ 기호 + 시스템 보고체**(TTS 부적합) | ⚠ 워프 신호 확인. 우르사 메이저 본체 + 친위대 15척 + 치크스 정찰대 14척. 총 30기. |
| 484 | **⚠ 기호 + 수치 보고체** | ⚠ 우르사 메이저 보이드 방어막 — 0.3초 윈도우 확인. 일점사 가능. |
| 485 | 시스템 보고체 | 우르사 메이저 격파 확인. 아이젠클로 사령관 함선 동시 파괴. 적 함대 — 잔존 0… |

| 487 | **영문 대사**(가가린?) | 사령관. So I am the first comrade in a hundred years… I'll take you anywhere. |

## 3. 녹음 ≠ 대본 — 녹음에 대본에 없는 문장이 섞임 (대본 보강 또는 재녹음)

스튜디오에서 추가 발화한 듯, 대본보다 문장이 더 들어가 인접 클립으로 번짐. **대본을 실제 녹음에 맞춰 보강 후 재분할** 권장.

- **이휘소 003~005** — 녹음에 "내 방정식이 마침내 쓰일 곳을…", "보이드 에너지를 실으면 저 머리도 벨 수 있습니다", "없던 미사일 화력이 나옵니다. 그게 봉쇄를 푸는 열쇠예요" 등 **대본에 없는 문장 다수**. (대본 5줄 < 녹음 8문장)
- **장영실 015~016** — 녹음에 "그 탄도 방정식 거북선에 실을 수 있어요. 당신과…", "나 손을 맞추면 이 함대의 미사일이 달라집니다" 추가.
- **이순신 038~039** — 녹음에 "열어라. 아이젠클로가…", "이렇게까지 숨겨둔 곳이라면 보통 인물이 아니다" 추가.
- **마르코 폴로 301** — 대사가 "**볼칸**이 내부 노선을 줬어" → 이름 변경으로 **"불칸이…"** 로 수정됨. 기존 마르코 음성은 '볼칸'으로 발음 → 해당 줄 **재녹음 필요**.
- **백구 136** — 대본 "먼저 **지구를 해방**해야" ↔ 녹음 "먼저 **우르사 메이저를 격파**해야". **내용 자체가 다름** → 대본/녹음 중 하나로 통일 필요.

## 4. 변수·코드·메타가 남은 대본 — TTS 부적합 (표현 수정 필요)

UI/시스템 동적 문자열. 빈 변수 슬롯·내부 코드·메타 표기가 남아 음성으로 부적합. **고정 음성 대상에서 제외하거나, 변수 없는 일반 표현으로 바꿔야 함.**

| 클립 | 문제 | 대본 |
|---|---|---|
| 백구 020 | 내부 코드 `SW01`/`SA01` (녹음은 "전설"로 읽음) | SW01 무기 세트 + SA01 장갑 세트 자동 장착 완료… |
| 백구 022 | 영문 `HMS Victory` | …옛 지구 해군 식별 코드 'HMS Victory'. |
| 백구 039 | **빈 변수** "지금 위치: **.**" | 지금 위치: . 행성 광장에서 퀘스트·상점·주점 이용 가능. |
| 백구 041 | **빈 변수** "후퇴해서 **+이** 됐어" | 강화 실패... 이 단계 후퇴해서 +이 됐어… |
| 백구 043 | **빈 변수 다수** (팔콘 **척**, 설계도 **장**, VC **개**, VE) | …팔콘 척, 신화 설계도 장, 신화 파츠 5종, VC 개, VE 을 남겼어… |
| 백구 076 | **빈 변수** "**은** 하선했어" | 합류! 은 하선했어. |
| 백구 087 | **빈 변수** "보너스 **×배**" | 레벨 보너스 ×배! |
| 백구 099 | **메타 `ACT 3`** (녹음은 "조금 더 진행해야"로 우회) | …ACT 3에 도달해야 진입할 수 있어! |
| 백구 104 | **빈 변수** "**은** 산지야" | 은 산지야. 상점에서 구할 수 있어… |
| 넬슨 008 | 영문 `England expects` | England expects— 아니. 이제는 지구가 기대한다… |

> 백구의 빈 변수 줄(039·041·043·076·087·104)은 **런타임 변수가 들어가는 동적 UI 멘트** → 고정 음성 녹음 대상에서 제외하는 것이 맞음. ACT/코드/영문은 i18n 정합 규칙(코드네임·메타 금지)에 따라 일반 표현으로 교체 후 필요 시 재녹음.

## 요약

- **1·2번(치크스 이후 475~491):** 아직 음성 없음 → 기호/영문/네이밍 정리 후 생성.
- **3번:** 녹음에 추가 문장 → 대본 보강 후 재분할(이휘소·장영실·이순신·백구136).
- **4번:** 변수/코드/메타 잔존 → 동적 멘트는 음성 제외, 나머지는 표현 교체.
- 그 외 정합도 낮은 줄은 **STT 오인식일 뿐 클립 위치 정상** → 조치 불필요.
