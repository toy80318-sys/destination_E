# 음성(보이스) 적용 가이드 — 컷신·팝업 대사 음성 재생

> 무음 분할로 만든 줄별 보이스 클립을 게임 대사에 연결하는 방법. 코드 적용은 Claude Code.

## 0. 현재 보유 클립 (계속 추가됨)
| 캐릭터 | 폴더 | 클립 수 | 대사 수 | 매칭표 |
|---|---|---|---|---|
| 백구 | clips/baekgu/ | 165 | 166 | voice_map_baekgu.csv |
| 사령관(주인공) | clips/commander/ | 45 | 43 | voice_map_commander.csv |
| 이순신 | clips/yisunsin/ | 66 | 64 | voice_map_yisunsin.csv |

- 파일명: `<캐릭터>_NNN.mp3` (NNN=대사 순서). 나머지 캐릭터는 스튜디오 생성→업로드→Cowork 분할로 동일 규칙 추가.

## 1. 에셋 배치
- 작업본 위치: `01_GDD/voice/clips/<캐릭터>/`
- **게임 배치 경로(권장):** `02_Assets/audio/voice/<캐릭터>/` 로 복사. `package.json`의 `build.files`에 포함되는지 확인(빌드에 들어가야 함).

## 2. 대사 ↔ 클립 연결 (택1)
- **(A) voiceId 필드(권장):** 각 컷신/팝업 대사 객체에 `vid:"yisunsin_007"` 추가 → 출력 시 `02_Assets/audio/voice/yisunsin/yisunsin_007.mp3` 재생.
  - 매칭표 CSV(clip_file↔line_text)로 어느 대사인지 확인해 vid 채움.
- **(B) 매핑 테이블:** 캐릭터별 `{대사키: 클립번호}` 데이터를 따로 두고 조회.
- i18n 텍스트(자막)는 그대로, **오디오만 부가**(자막+보이스).

## 3. 재생 로직(개요)
- 컷신 라인 표시 시 `vid` 있으면 해당 mp3 재생(기존 AudioMgr 또는 `new Audio(src).play()`). 없으면 자막만.
- 팝업·백구 멘트도 동일. 설정에 **보이스 on/off·볼륨**, 모바일은 사용자 입력 후 재생(자동재생 정책).
- 라인 넘어갈 때 이전 보이스 정지(중복 재생 방지).

## 4. 개수 불일치 주의(분할 특성)
- 백구 165/166, 사령관 45/43, 이순신 66/64 — "…" 등 내부 쉼으로 일부가 분할/병합되어 번호가 한두 칸 밀릴 수 있음.
- → **매칭표 CSV를 들으며 확인**해 vid 확정. 어긋난 소수만 Cowork에서 재분할/병합으로 1:1 보정 가능.

## 5. 작업 순서
1. `clips/` → `02_Assets/audio/voice/` 복사 + build.files 포함 확인.
2. 매칭표로 각 대사에 `vid` 부여(백구·사령관·이순신부터).
3. 대사 렌더부에 vid 재생 로직 + 설정(보이스 on/off·볼륨).
4. 인게임 컷신/팝업 보이스 동기 확인 → node --check → 커밋.

> 나머지 캐릭터(장영실·가가린·테슬라·광개토·넬슨·아인슈타인·마르코·이휘소·보스·NPC 등)는 스튜디오 통짜 생성→업로드→Cowork 분할→이 폴더 규칙으로 계속 추가.
