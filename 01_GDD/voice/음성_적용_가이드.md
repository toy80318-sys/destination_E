# 음성(보이스) 적용 가이드 — 컷신·팝업 대사 음성 재생

> 무음 분할로 만든 줄별 보이스 클립을 게임 대사에 연결하는 방법. 코드 적용은 Claude Code.

## 1. 에셋 위치 / 네이밍
- 현재(작업): `01_GDD/voice/clips/<캐릭터>/<캐릭터>_NNN.mp3`
  - 백구: `clips/baekgu/baekgu_001.mp3 … _165.mp3`
  - 사령관: `clips/commander/commander_001.mp3 … _045.mp3`
- **게임 배치 권장 경로:** `02_Assets/audio/voice/<캐릭터>/` 로 복사해 사용(빌드 포함 목록 `package.json build.files` 확인).
- 번호(NNN)는 대사 순서. 매칭표: `voice_map_baekgu.csv`, `voice_map_commander.csv` (clip_file ↔ line_no ↔ 대사텍스트).

## 2. 대사 ↔ 클립 연결 방식 (택1)
- **(A) 데이터에 voiceId 필드 추가(권장):** 각 컷신/팝업 대사 객체에 `vid:"baekgu_012"` 같은 필드를 넣고, 대사 출력 시 `02_Assets/audio/voice/baekgu/baekgu_012.mp3` 재생.
  - 매칭표 CSV의 line_text로 어떤 대사인지 확인해 vid를 채움.
- **(B) 순서 인덱스 매핑 테이블:** 캐릭터별 `[대사키→클립번호]` 맵을 별도 데이터로 두고 조회.
- i18n 텍스트는 그대로 두고 **오디오만 부가**(자막+보이스). 텍스트 변경 시 vid 유지.

## 3. 재생 로직(개요)
- 컷신 라인 표시 시: `vid` 있으면 해당 mp3 재생(`new Audio(src).play()` 또는 기존 AudioMgr 활용). 없으면 무음(자막만).
- 팝업/백구 멘트도 동일 — baekgu_* 클립을 멘트 키에 매핑.
- 옵션: 설정에 "보이스 on/off", 볼륨. 모바일 자동재생 정책 고려(사용자 입력 후 재생).

## 4. 현재 매칭 주의(개수 불일치)
- 백구: 대사 166 vs 클립 165 — 한 곳에서 인접 대사가 **병합**되어 이후 번호가 한 칸씩 밀릴 수 있음.
- 사령관: 대사 43 vs 클립 45 — "…" 끊김 대사 일부가 **둘로 분할**되어 밀림.
- → **매칭표 CSV를 들으며 확인**해 vid를 확정할 것. 어긋난 소수만 클립 병합/재분할 또는 vid 보정.
  (원하면 Cowork에서 특정 구간 재분할로 1:1 맞춤 가능.)

## 5. 작업 순서
1. `clips/` → `02_Assets/audio/voice/` 복사, build.files 포함 확인.
2. 매칭표로 각 대사에 `vid` 부여(백구·사령관부터).
3. 대사 렌더부에 vid 재생 로직 추가 + 설정(보이스 on/off·볼륨).
4. 인게임에서 컷신/팝업 보이스 동기 확인. node --check 후 커밋.

> 나머지 캐릭터는 스튜디오에서 통짜 생성→업로드→Cowork 무음분할→동일 폴더 규칙으로 추가.
