## 1) 적군 등장 — 기존 팝업 흐름 유지 (통합하지 말 것)

- 등장 팝업 **1회로 줄이지 말고 기존대로** 둔다.
- **적군 멘트 팝업(몰입 요소) 유지·보강** — 적 세력(적군/해적/치크스/보스)별 도발·등장 멘트를 실감나게. i18n 키 세트로 분리.

## 2) 상대 함대 스펙 팝업 — 백구 하단 배치 + 이미지 2배

- 상대 함대 스펙(세력·대표 함명·척수, 총 HP/실드, 평균 ATT/INT/TEC/DEF, 아군 대비 위협도%) 요약 카드.
- **백구 이미지 + 백구 멘트를 카드 하단에 배치.** (좌측 아님 — 하단.)
- **백구 이미지 크기 현재의 2배로 확대.**
- 백구 멘트 = 분석 브리핑 톤. 예) 백구: "분석 완료 — 적은 해적 중형 3척, 화력은 우리보다 약 20% 높아요. 미사일 화망에 주의하세요."

## 3) 전투 종료 후 — 적군/관계자 멘트 (매우 실감나게)

전투 결과 팝업(`report-popup.js`)에 종료 멘트 영역 추가. 상황별 분기:
- **잡혔던 상인 — 감사 멘트** (구출/해방된 상인). 예: "사령관님 아니었으면 저놈들 화물칸에서 끝날 뻔했소. 이 은혜 잊지 않겠습니다."
- **구출된 과학자 — 감사 멘트** (이휘소 등 합류 맥락). 예: "당신들이 와줄 줄… 데이터를 지켜냈습니다. 함께 가겠습니다."
- **적군 — 후회 멘트** (패배). 예: "이 함대를… 얕봤군. 빌어먹을…"
- **적군 — 도망 멘트** (적 퇴각/일부 생존). 예: "퇴각! 전부 퇴각하라! 오늘은 여기까지다!"
- 세력·등급별 i18n 멘트 배열에서 조건 선택. 보상 항목과 한 팝업에 자연 배치(상단 멘트 → 보상 리스트).

## 4) 특별 보상 획득 — 폭죽 + 백구 하단 멘트

- **특별(전설·신화·스토리) 보상 획득 시 폭죽 효과** — 기존 `_fireFireworks()` 호출.
- 보상 팝업 **하단에 백구 이미지 + 백구 멘트** — **어떤 경과로 이 아이템을 얻었는지** 몰입형으로 설명. 예: 백구: "이건 아이젠클로 단조공장 깊은 곳에서 끌어낸 거예요 — 거북선의 마지막 조각이죠. 드디어!"
- 멘트는 보상 종류/획득 경로(전투·퀘스트·가챠·경매)별 분기, i18n 키.

## 5) 불필요 문구 삭제

- 팝업에서 **"누적 등장 4회" 류 카운터 문구 삭제.**
- 팝업에서 **강화 수치(×N 등 내부 수치 노출) 삭제** — 몰입 저해 요소 제거. (스펙 요약의 의미 있는 수치는 유지하되, "누적/강화 배수" 같은 시스템 노출만 제거.)
- 정확한 문자열 위치는 report-popup.js·combat.js·관련 카드에서 검색해 제거.

## 6) 버튼 위치

- **전투(시작) 버튼 = 항상 팝업 우측 하단.** (전투 관련 **팝업**의 시작 버튼 공통 — 브리핑 팝업 combat.js L98~99 등.)
- ⚠️ **개정(2026-06-18): 전투 모드(전투 화면) 중 "일시정지"·"도망가기" 버튼은 기존 위치 그대로 유지** — 이동하지 말 것. (앞서의 "도망 버튼 좌측 하단" 지시 철회.)
- 즉, 변경 대상은 **팝업의 전투 시작 버튼(우측 하단)뿐**. 전투 HUD의 일시정지·도망가기 위치는 현행 유지. 버튼 라벨·기능 모두 유지.

## 7) 공통 — 멘트 글씨 1.5배 + 인물 멘트 보강

- 등장·통행료·보상 팝업의 **상단 대사 멘트 글씨 1.5배**(예 `shakedown-popup.js` 16px→24px). 보조 텍스트·수치는 제외, **대사 멘트만**. `line-height` 동반 조정, `word-break:keep-all` 유지.
- 모든 멘트 세계관 1인칭 몰입형, i18n 키로 분리(하드코딩 금지).
