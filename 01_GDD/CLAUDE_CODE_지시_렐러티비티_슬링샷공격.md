# Claude Code 지시서 — 렐러티비티(LGD03) 스트라이크 크래프트(슬링샷 발진) 공격 연출

> 작성: Cowork 기획 세션. 코드 적용은 Coder(Claude Code) 권한.
> 대상 함선: **LGD03 = 렐러티비티(신화)** — 아인슈타인 상대성 테마. 백구 멘트 `baekgu.einsteinRelativity`: "시간축이 휘어진다 — 적은 한 번 맞는데 우린 네 번 친다."
> 성격: **연출(VFX/애니메이션) 전용.** 데미지 수치·전투 밸런스는 변경하지 않는다(기존 전투 로직이 계산한 피해를 그대로 사용, 슬링샷은 시각 표현). 밸런스 변경 필요 시 Director 확인.

> 발진 소형정 명칭 = **슬링샷(Slingshot)**. 상대성 함선답게 **슬링샷(중력도움) 기동**처럼 가속해 튕겨나갔다가 복귀하는 궤도 연출 권장.

## 1. 개요 — 무엇을 만드나
렐러티비티가 공격 차례에, **본체 크기의 50% 소형 함선 '슬링샷'을 발진**시켜 적에게 돌격 → **레이저 발사** → **본체로 귀환**하는 캐리어형 공격 연출. 본체는 제자리를 지키고 슬링샷만 왕복.

## 2. 트리거
- 전투 중 LGD03(렐러티비티)이 **공격 액션을 수행하는 시점**에 슬링샷 시퀀스 시작.
- 식별: 공격 주체 함선의 id/baseId가 `LGD03`(또는 신화 렐러티비티 변형)일 때만. 다른 함선은 기존 연출 유지.
- 상수로 분기(하드코딩 금지): `const SLINGSHOT_SHIPS = ['LGD03'];`

## 3. 연출 시퀀스 — "출격 → 근접 선회 4회 공격 → 귀환"을 반복
`_cbStartAnimLoop`의 프레임 업데이트에 "슬링샷 액터"를 추가해 상태머신으로 진행. **1 사이클 = 출격→선회공격→귀환**, 함선의 공격(턴/연사) 횟수만큼 **사이클 반복**(나갔다 → 돌아오기 → 다시 나가기).
1. **발진(LAUNCH, ~0.12s):** 본체 선수에서 슬링샷 스폰, 가속/엔진 글로우.
2. **돌격(DASH, ~0.3s):** 대상 적 함선으로 슬링샷 기동(이즈인아웃 곡선, arc).
3. **근접 선회 공격(STRAFE, ~0.5s):** 슬링샷이 **적 함선에 매우 가깝게 선회(공전)** 하며 **레이저·미사일을 섞어 4회 공격**.
   - 무기 = 슬링샷이 발사. 레이저 = `_cbAddBeamAndHit(from=슬링샷,to=적)`, 미사일 = `_cbAddMissileSalvo(from=슬링샷,to=적)` 재사용. 4타는 레이저/미사일 혼합(예: 레2+미2 또는 함선 무기구성 비율).
   - 선회 = 적 함선 주위 작은 반경 궤도(orbit)로 1바퀴 돌며 각 공격을 발사 위치에서 쏨.
4. **귀환(RETURN, ~0.3s):** 본체로 복귀.
5. **반복(LOOP):** 본체에 닿으면 곧바로 재출격 → 2~4 반복(공격 횟수만큼). 마지막 사이클 후 디스폰(페이드).
- 데미지 텍스트(`_cbAddDmgText`)는 각 타격과 동기. **총 피해량은 기존 계산값과 동일**(다회 공격은 시각 분할, 합계 불변).

### 다중 슬링샷 — 궤도 겹침 방지 (3중)
- 렐러티비티가 여러 척이거나 한 함선이 여러 슬링샷을 동시 운용할 때, 각 슬링샷에 **tier(0/1/2)를 순환 배정**.
- tier별로 **선회 반경(tierRadius)·수직 높이(tierY)·선회 방향(tierDir)·시작 위상(tierPhase)** 을 다르게 적용 → 궤도가 안/중/밖 + 위/아래 + 시계/반시계로 분리되어 **겹치지 않음**.
- 같은 tier가 또 필요하면 위상(phase)을 추가로 어긋내(예: +60°) 충돌 방지. 발진 타이밍도 소폭 스태거(±80ms).

## 4. 슬링샷 비주얼
- 스프라이트 = **본체와 동일한 함선 이미지**를 50% 크기로. `_combatShipImgSrc(LGD03)` 로 소스, 크기 = `_shipDrawSize(해당함선) * 0.5`.
- 렌더는 `_drawShipUnit` 경로 재사용(회전: 진행 방향으로 heading). 이미지 로드 실패 시 `_drawShipVector` 폴백(작은 삼각형).
- 엔진 트레일/글로우는 기존 전투 글로우 스타일(시안 계열). **무기 = 슬링샷이 발사**: 레이저(`_cbAddBeamAndHit`, 시안/화이트) + 미사일(`_cbAddMissileSalvo`, 골드 탄). 4타를 레이저/미사일 혼합.
- 적 함선에 **밀착 선회**하므로 슬링샷↔적 간 짧은 빔/근접 미사일로 보이게(발사 원점=슬링샷 현재 위치).

## 5. 수치/타이밍 상수 (combat.js 상단 또는 const 블록에 분리)
```
const SLINGSHOT = {
  scale: 0.5,            // 본체 대비 슬링샷 크기
  shotsPerCycle: 4,      // 1사이클당 근접 공격 횟수(상대성 "네 번 친다")
  weapons: ['laser','missile','laser','missile'], // 4타 무기 순서(혼합)
  orbitRadius: 46,       // 기본 근접 선회 반경(px) — 다중일 땐 아래 tier로 대체
  cycles: 'attackCount', // 사이클 반복 수 = 함선의 공격(연사/턴) 횟수에 맞춤
  tLaunch: 120, tDash: 300, tStrafe: 500, tReturn: 300, // ms (1사이클)
  arc: 40,               // 돌격 곡선 높이(px)
  beamColor: '#bfefff', missileColor: '#ffd25a',
  // ── 다중 슬링샷: 궤도 겹침 방지 3중(반경/높이/방향/위상 분산) ──
  tiers: 3,
  tierRadius: [40, 66, 92],   // 3중 궤도 반경(안→밖)
  tierY:      [-20, 0, 20],   // 궤도 수직 높이 오프셋(아래/중앙/위)
  tierDir:    [1, -1, 1],     // 선회 방향(시계/반시계 교차)
  tierPhase:  [0, 120, 240]   // 시작 위상(deg) — 같은 tier여도 어긋나게
};
```
- 모두 상수. 값 바꿔도 한 곳만 수정되게.

## 6. 성능 / 안정성
- 슬링샷 액터는 **오브젝트 풀링**(combat.js 기존 dmgText/beam 풀 패턴 따라). 동시에 여러 렐러티비티가 공격해도 풀 재사용.
- 애니는 `_cbStartAnimLoop` 한 루프 안에서 deltaTime 기반 진행(별도 setInterval 금지).
- 전투 진행을 막지 않음(비차단). 공격 해상도(데미지 적용)는 기존 시점 유지, 슬링샷은 그 위 레이어.
- 모바일 60fps 유지: 슬링샷 1기 + 빔 4발 수준이라 부담 적음. 오프스크린 캐시 활용.
- 일시정지(`toggleCombatPause`) 시 슬링샷 애니도 정지.

## 7. 연동 지점 (combat.js)
- `_cbStartAnimLoop` — 슬링샷 액터 업데이트/그리기 추가.
- `_drawShipUnit` / `_drawShipVector` / `_shipDrawSize` / `_combatShipImgSrc` — 슬링샷 렌더에 재사용.
- `_cbAddBeamAndHit` — 레이저, `_cbAddMissileSalvo` — 미사일 (4타 혼합).
- 공격 수행 함수(LGD03 공격 처리부) — 트리거에서 `spawnSlingshot(srcShip, targetShip)` 호출.
- 신규 함수 제안: `spawnSlingshot(src, tgt)` (액터 생성), 루프 내 `_updateSlingshots(dt)` / `_drawSlingshots(ctx)`.
