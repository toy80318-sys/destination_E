## 1. 프로젝트 개요

### 1.1 엘리베이터 피치

> "100년 전 치크스 제국에 의해 파산한 지구를 구하기 위해, AI 기계 진돗개 '백구'가 100년간 구축해 놓은 위장 상단을 이어받은 사령관이, 전설의 영웅 8인·동료 141명과 함께 우주 무역·부동산·전투로 자본을 축적하고, 지구 궤도를 봉쇄한 행성형 요새 '우르사 메이저'를 격파하는 하드코어 우주 자본주의 RPG"

### 1.2 핵심 게임 가치 (Core Pillars)

| 필러 | 설명 | 레퍼런스 |
|------|------|----------|
| 성간 무역 경제 | 7대 문명권 간 21종 특산물, ΔR 마진 4~5배 | Galaxy on Fire 2 |
| 하드코어 로그라이크 전투 | 16v16 턴제, 전멸 시 자산 50% 포맷 패널티 | FTL |
| 부동산 타이쿤 | 행성 경매 낙찰, 총독 파견, 턴당 세금 패시브 인컴 | 일곱 개의 별 |
| 한국 정체성 서사 | 이순신·광개토대왕·장영실이 전설 영웅으로 등장 | 오리지널 |
| AI 동반자 백구 | 100년 대기한 기계 진돗개, 위트 있는 독설 브리핑 | 오리지널 |
| 숨겨진 서사: 이휘소 | 빅뱅 직전의 수학을 아는 물리학자의 유언 | 오리지널 |

### 1.3 플레이어 초기 설정 변수

| 변수 | 내용 | 적용 범위 |
|------|------|---------|
| User_Gender | 남/여 선택 | NPC 대사 인칭 분기 |
| User_Name | 사령관명 | 백구 호칭, 랭킹 UI |
| Company_Name | 무역 상단명 (기본: 빅 픽처 스페이스) | HUD 타이틀, 세금 대시보드 |
| Ship_Name | 격납고 초기 함선명 (기본: 머스탱) | 함선 데칼, 상태창 |

### 1.4 게임 유형 & 장르

- **장르**: SF 우주 경제 부동산 타이쿤 × 턴제 전술 RPG × 로그라이크
- **플랫폼**: PWA (Progressive Web App) — Mobile First, PC 지원
- **플레이 시간**: 첫 클리어 약 40~60시간 / NG+ 무한
- **결제 모델**: 부분 유료화 (F2P + VC 인앱 결제)
- **연령 등급**: 12세 이상 (전략·경제 요소 위주, 과금 주의)

## 4. 세계관 및 메인 서사

### 4.1 지구의 파산 — 100년 전

100년 전, 우주 중심부의 생체 괴수 제국 **'치크스 제국(Cheeks Empire)'** 이 지구를 습격했다. 치크스는 지구 궤도에 행성형 거대 요새 모함 **'우르사 메이저(Ursa Major)'** 를 영구 주둔시키고, 시공간 왜곡 성간 안개로 태양계를 봉쇄했다. 살아남은 지구 저항군은 차가운 지하 방공호에 격리됐다.

### 4.2 이휘소 박사의 마지막 계산 (신규 v6.0)

100년 전 지구 함락 직전, 한국의 이론물리학자 **이휘소(李輝昭) 박사**는 치크스 우르사 메이저의 에너지원이 '빅뱅 특이점 반응로'임을 간파했다. 그는 임박한 죽음을 앞에 두고 단 하나의 방정식을 완성했다:

> **"우르사 메이저 5페이즈의 절대 무적 실드는 빅뱅 초기 플랑크 상수의 역수를 입력해야만 해제된다."**

이 방정식의 쪽지를 아인슈타인의 제네시스 데이터에 숨겨두었고, 사령관이 아인슈타인을 영입하기 전까지는 절대 해독되지 않는다. 이것이 이휘소 박사의 유언이자, 게임 최후 결전의 열쇠.

### 4.3 보이드 균열의 기원

치크스의 봉쇄 무기 **'제네시스 단층 포격'** 은 은하계 오각형 격자의 황금비 수렴점(φ=1.618)을 정조준해 시공간을 찢었다. 부작용으로 4개의 영구 균열(P27~P30)이 새겨졌다. 균열은 생체를 거부하고 기계와 수학을 허용한다.

### 4.4 사령관의 각성

100년 전 아인슈타인이 P30에서 설계한 **역시간 전송 방정식**이 100년 후의 사령관을 P01(프록시마 b)로 끌어당겼다. AI 기계 진돗개 **백구**가 맞이한다.

> **백구**: "내가 폐지 주워서 이만큼 상단 세워놨으니, 돈 벌어서 장비 사고 전설의 영웅들 싹 다 징발해서 지구 구하러 가자."

### 4.5 3막 서사 구조

| 막 | 구간 | 핵심 사건 |
|---|------|---------|
| ACT 1 | P01~P08 (수퍼비아+아우레우스) | 각성·상단 설립·이순신+장영실 영입 |
| ACT 2 | P09~P16 (메카니카+크리그) | 테슬라·넬슨 영입·치크스 전초 격파 |
| ACT 3 | P17~P30 (치크스+보이드균열) | 아인슈타인 영입·이휘소 방정식 해독·우르사 메이저 최종전 |

### 5.5 ΔR 무역 마진 공식

```
ΔR = |R_i - R_j| + 0.1 × min(|θ_i - θ_j|, 360 - |θ_i - θ_j|)

```

## 15. 16v16 전술 전투 시스템

### 15.1 전투 아키텍처

- **엔진**: Phaser 3 WebGL 독점 세션
- **방식**: 스택형 턴제 격돌
- **규모**: 아군 최대 16대 vs 적 최대 16대
- **타임라인**: React HUD 상단 실시간 턴 오더 칩 표시

### 15.2 핵심 공식

**턴 우선순위**
```
T_priority = TEC_base × (1 + Random(0.0, 0.05)) + 제독_스탯_가중치
```

**명중/회피 판정**
```
P_hit(%) = max(5, min(100, 85 + (DEX_attacker - TEC_defender) × 0.5))
```

**치명타 확률**
```
P_critical(%) = max(1, min(50, 5 + (DEX_attacker - TEC_defender) × 0.2 + 무기_크리_버프))
```

**최종 피해**
```
최종_피해 = max(1, (원시_DEX_대미지 × 크리_배율 - 장갑_정량감쇄) × (1 - 장갑_효율_감소율))
크리_배율: 일반=1.0, 크리티컬=1.5, 크리그_패시브=1.8
```

### 15.3 나포(Capture) 시스템

선행 조건: 적 INT(실드) = 0 AND HP ≤ 30%
```
P_capture(%) = max(0, min(95, (LOY_commander/100) × (30 + (DEX_attacker - HP_target) × 0.3) + 드론_버프))
나포 드론 V1: +0% / V2: +15%
```

### 15.4 전멸 패널티 (Hardcore Format)

기함 HP=0 → **기함 제외 전 호위함 + 화물 + 보유 크레딧 50% 영구 삭제** → 최근접 수퍼비아 안전 정거장 리스폰

**방주 프로토콜 예외**: 아인슈타인 H06 생존 탑승 시 자산 유실 0%, 교전 1턴 전 세이브로 타임점프 부활

### 22.3 Firebase Security Rules (핵심)

```javascript
// Firestore Rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /gameStates/{userId} {
      allow read, write: if request.auth.uid == userId;
    }
    match /leaderboard/{document=**} {
      allow read: if true;
      allow write: if false; // Cloud Functions만 기록
    }
  }
}
```
