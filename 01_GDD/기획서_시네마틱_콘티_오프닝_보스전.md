# 기획서 — 시네마틱 콘티: 오프닝 & 보스전 2026-07-09

> 목적: 오프닝과 보스전 시네마틱을 **전문 연출 문법**으로 콘티화 → 스토리와 시네마틱이 자연스럽게 이어지게.
> 엔진 현실: 본 게임 컷신 = 풀스크린 **키아트(스틸) + 자막 + SFX + 음성**(`STORY_SCENES_PC.showCharDialog`). 실시간 3D 아님.
>   → 각 "샷"은 **한 장의 연출된 스틸(또는 라이트 모션: 팬·줌·파티클)**. 카메라 지시는 **이미지 구도·다음 컷 전환 의도**로 사용.
> 연계: 캐릭터/함선은 `기획서_디테일시트_캐릭터_함선.md`의 승인 시트 재사용. 오프닝 대사 SSOT = `기획서_오프닝_프롤로그.md`(백구 1인칭 16비트).

## 0. 감독 연출 문법 (리서치 요약 → 우리 규칙)

리서치 핵심(영화 촬영·게임 시네마틱·스토리보드):

| 도구 | 의미 | 우리 게임 적용 |
|---|---|---|
| **Extreme Long Shot(ELS)** | 압도적 스케일 | 봉쇄 함대·행성 규모 = 공포/위엄 |
| **Long Shot** | 감정적 거리·고립 | 프록시마B 변두리의 백구(외로움) |
| **Close-Up / ECU** | 친밀·감정 | 박사 마지막 얼굴·영웅 각성 눈 |
| **Low Angle(로우앵글)** | 힘·위협·영웅 | 영웅 등장·거북선·보스 위압 |
| **High Angle** | 무력·내려봄 | 격침 직전 아군·패배 순간 |
| **Dutch Angle(더치앵글)** | 긴장·불안정·주관 | 보스전 돌입·시공 왜곡(아인슈타인) |
| **Establishing Shot** | 장소 소개 | 각 막의 첫 컷(행성·전장) |
| **Aerial/Overhead** | 전황 조망 | 함대 진형(학익진) 부감 |
| **Tracking / Push-in** | 주목·긴장 고조 | 정지 스틸에 라이트 줌으로 대체 |

3막 리듬(오프닝·보스 공통): **① 정적 설정(넓게) → ② 긴장 상승(가까이·기울여) → ③ 폭발·해소(로우앵글 임팩트)**. 컷 길이는 대사 호흡(한 문장=한 컷).

시각 톤: 진영 팔레트 바이블 준수(지구=따뜻/청록, 치크스=보라/병록, 크리그=마그마, 보이드=심연).

## 1. 오프닝 콘티 — "봉쇄된 하늘" (16비트, 새 게임 1회)

> 대사·음성은 기존 프롤로그(백구 1인칭, vid 660~673) 그대로. 아래는 **비트별 화면 콘티**.

| # | 비트(대사 요지) | 씬/배경 | 샷·구도 | 연출·전환·SFX |
|---|---|---|---|---|
| 1 | (자막) 하늘이 무너지는 소리 | 검은 화면 | — | `[sfx 콰광]` 검은 화면에 붉은 섬광 1프레임 |
| 2 | 백 년 전 그날 | 봉쇄 궤도 ELS | **ELS** 지구 위 검은 함대 무한 | 느린 페이드인, 앰비언트 로우 드론 |
| 3 | 모든 무기가 숨을 멈췄다 | 지구 방어선 붕괴 | **High Angle** 무력한 인류 함대 | 붉은 폭발 점점(치크스+크리그 실루엣) |
| 4 | 불타는 연구실 | 박사 연구실 | **ECU** 박사 얼굴(연기 너머) | 따뜻 키라이트 꺼져감, `[sfx 불길]` |
| 5 | 별을 향해 희망을 | 발사 순간 | **Low Angle** 캡슐 상승 궤적 | 어둠 뚫는 한 줄기 빛(림라이트) |
| 6 | 하나는 백구, 하나는 사람 | 캡슐 2 | Medium 2샷(백구 코어+캡슐) | 두 광점 분리 |
| 7 | 이어 일곱 영웅 | 캡슐 산개 | **Aerial** 7 궤적이 별들로 | 하나·둘…일곱 카운트 라이트 |
| 8 | 마지막, 가장 늙은 학자 | 8번째 캡슐 | Long Shot 뒤따르는 궤적 | 살짝 다른 색(아인슈타인 퍼플) |
| 9 | 그 빛은 흔적 없이 사라졌다 | 성간 어둠 | **ELS** 어둠에 삼켜지는 광점 | 신호 페이드→무음(불길한 정적) |
| 10 | 간발의 차, 연구실이 부서졌다 | 지표 폭발 | **High Angle** 상승 vs 하강(대비) | `[sfx 대폭발]` 화면 백열 플래시 |
| 11 | 누가 살아남았을까 | 잔해 우주 | Long Shot 표류 잔해 | 침묵 2초(호흡) |
| 12 | 백 년이 흘렀다 | 시간 경과 | 디졸브(별 회전 타임랩스) | 색 온도 차갑게 전환 |
| 13 | 프록시마B, 묘비 같은 폐선 | 변두리 궤도 | **Long Shot** 고립된 백구 함 | 외로움 = 넓은 빈 프레임 |
| 14 | 에너지 7%, 전원을 끄지 않았다 | 백구 코어 | **ECU** 깜빡이는 코어 광 | 심박 같은 점멸 SFX |
| 15 | 오직 한 점 — 잃어버린 고향 | 백구 시점 | **POV** 멀리 푸른 지구 1점 | 슬로우 푸시인(줌) |
| 16 | 오늘, 희미한 신호 하나 | 통신 각성 | **CU** 백구 포트레이트 각성 | `[sfx 삐— 신호]` 시안 발광 → 허브 진입 |

전환 규칙: 1~11 회상(차갑고 비장, 넓은 샷 위주) → 12 시간축 디졸브 → 13~16 현재(따뜻·결의, 가까운 샷). **건너뛰기(ESC) 가능, `G._prologueSeen` 1회.**

## 2. 보스전 시네마틱 콘티 (공통 3막 구조 + 보스별)

모든 보스전 = **[등장 컷신] → [전투] → [격파/전환 컷신]**. 등장은 **위압(로우앵글) + 더치앵글(불안정)**, 격파는 **해방(밝아짐)**.

### 2-A. 중간보스 — 아이젠클로 (P16 페스작센, 크리그 집행관)
> 실제 트리거: 퀘스트 `p4_q1907` 수락 → `p4_eisenklau` 컷신 → 전투(이미 구현).

| 단계 | 샷·구도 | 연출 |
|---|---|---|
| 등장1 | **Establishing** 페스작센 단조 공장(마그마·용접 불꽃) | 붉은 용광로 톤, 열기 아지랑이 |
| 등장2 | **Low Angle** 2배 크기 아이젠클로 기함 부상 | 과잉 장갑 실루엣, 그림자로 아군 덮음 |
| 등장3 | **ECU** 아이젠클로 "그 캡슐은 우리 방어 코어다" | 더치앵글(위협), 이순신 리액션 컷 |
| 전투 | (인게임) 학익진 = **Aerial 부감** 진형 강조 | — |
| 격파 | **Low Angle** 기함 붕괴 → 잔해서 이휘소 캡슐 회수 | 마그마 꺼지고 청록 림라이트(해방) |

### 2-B. 최종보스 — 우르사 메이저 (지구 해방)
| 단계 | 샷·구도 | 연출 |
|---|---|---|
| 등장 | **ELS** 지구를 가린 우르사 본체(압도적 스케일) | 무채+자주, 빛을 삼키는 실루엣 |
| 대치 | **CU** 사령관/백구 결의 vs **Dutch** 보스 | 컷백 리듬(가까움↔기울어짐) |
| 필살기 | 제네시스 임팩트/데스티네이션 어스 = **화면 백열** | 8영웅 의지 수렴 광(퍼플→화이트) |
| 격파 | **High→Low 전환**: 무너지는 보스 위로 떠오르는 아군 | 봉쇄 걷히고 지구 푸르게(엔딩 훅) |

### 2-C. 히든보스 — 블랙팔콘 / 보이드 (극악)
| 단계 | 샷·구도 | 연출 |
|---|---|---|
| 신호 | 검은 화면 + `[sfx 지지직]` 신호 잡음 | 자막만(의도적 무음, void_hiden) |
| 등장 | **Dutch + 거울대칭** 블랙팔콘(S10) 왜곡 등장 | 반물질 왜곡·비정형 기하 |
| 위압 | 극악 시 "1방 즉파괴" = **임팩트 컷**(화면 흔들림) | 붉은 경고 오버레이 |
| 격파/아웃트로 | 검은 함선 소멸 → 격침 함선 부활(victoryLine3) | 반전 카타르시스, 백구 놀람 |

## 3. 스토리↔시네마틱 자연스러운 연결 규칙
- **각 막의 첫 컷은 Establishing**(어디인지 즉시), **마지막 컷은 다음 훅**(왜 계속하는지).
- 회상=넓고 차갑게, 현재/각성=가깝고 따뜻하게(온도·거리로 시제 구분).
- 보스 등장은 **항상 로우앵글 위압 + 아군 리액션 컷**(위협의 무게를 인물 반응으로 전달).
- 대사 1문장 = 1컷(음성 호흡과 컷 길이 일치). 침묵 컷(2초)을 의도적으로 배치(비트 11·감정 여백).
- 음성 이미 존재분(프롤로그 660~673, 엔딩·보스 컷신 vid)과 **콘티 컷 순서·감정 톤 일치**.

## 4. 제작 순서(권장)
1. 디테일 시트(별도 기획서) 승인 → 진영/영웅 비주얼 확정.
2. 오프닝 16컷 키아트 생성(시트 재사용, 진영 팔레트 고정).
3. 보스 등장/격파 키아트.
4. 라이트 모션(팬·줌·파티클) 코드 연출은 `showCharDialog` 확장 여부 검토 후 Coder.
5. 음성 톤·컷 순서 대조 검수.
