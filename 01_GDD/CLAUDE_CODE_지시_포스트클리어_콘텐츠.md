- 행성 상태: `G.planets[pid] = {fog, owned, commerce}` — **제독권 = `owned`**, **투자 = `commerce`(100=만렙 가정)**. 행성 세력 = `PLANET_DEF[].f`.
- 함선 도감: `G.discoveredShips[]`. 특산물/파츠/행성 발견도 codex.js 추적.
- 신화 함선: `LGD03` = 렐러티비티(ships.js L43). 특수 ×5 패턴 = `LGD01_SP`(`_turtleSpecial`, maxHP×5, 전투 크기 스케일) 참고.
- 사령관 이름: `G.profile.name`, 허브 좌측상단 `#hub-cmd`(game.js L531). 폭죽: `_fireFireworks()`.

## 1-B. 탐색 도감 100% 컴플리트 보상 ⭐

- **조건:** 도감 전 항목(행성·함선·파츠·특산물·문명·인물) 100% 발견/해금.
- **보상: 특수 렐러티비티(LGD03_SP) 1회 지급** — 일반 LGD03(렐러티비티)의 **능력치 ×5**, **전투 시 함선 크기 ×1.5**.
  - 구현: `ships.js`에 `LGD03_SP` 추가 — `LGD01_SP`(거북선 특수) 패턴 복제. 기준 LGD03(maxHP245000·maxSH90000·ATT306·INT295·TEC255) × **5** = maxHP1225000·maxSH450000·ATT1530·INT1475·TEC1275, `price:0`, `_relativitySpecial:true`.
  - 전투 크기 ×1.5: combat.js 스케일 로직에서 `_relativitySpecial`/`LGD03_SP` → 1.5배(거북선 LGD01_SP 2배 처리부 인근).
  - 이미지: `img/ships/LGD03_SP.png` 필요(없으면 `img/ships/LGD03.png` 복사 폴백).
  - 지급은 도감 100% 달성 시 1회(중복 방지 플래그 `G.flags.codexCompleteReward`).

# ② 업적 / 별칭(타이틀) 시스템 ⭐

## 2-A. 시스템 동작

- 업적 달성 시 **별칭(title) 획득** → **백구 팝업으로 설명**(획득 별칭·효과 안내, `_fireFireworks()` 가능).
- 획득 별칭은 **사령관 이름 상단(좌측상단 `#hub-cmd` 영역)에 명칭으로 표시.**
- **좌측상단 사령관 이름 클릭 → 별칭 선택/변경 모달.** 선택한 별칭의 **효과가 발동**(동시 1개만 활성).
- 데이터 모델:
  - `G.profile.titles = []` (획득한 titleId 목록)
  - `G.profile.activeTitle = titleId|null` (현재 장착 — 효과는 이것만 적용)
  - 정의 테이블 `TITLES[titleId] = { nm:{ko,en}, cond:fn, effect:key, baekgu:{ko,en} }` (신규 데이터 파일 `js/data/titles.js` 권장 + i18n).
- 효과 적용: 가격 할인·확률·스폰 등은 **활성 별칭 기준**으로 해당 계산부에서 분기(하드코딩 금지, 효과 상수 분리).
- 달성 판정: 허브 진입/전투 종료/구매 등 적절한 훅에서 `cond` 평가 → 신규 달성 시 획득 처리.

> ⚠️ **효과 중첩 규칙(검증 보강 2026-06-18):** 별칭 효과는 **동시 1개(activeTitle)만** 적용 → 할인·배수 중첩 원천 차단. 단 **"데스티네이션 어스를 달성한"의 지구저항군 ×5 배수는 "구매한 일반 지구저항군 함선"에만 적용**하고, **벙커존 미니게임 보상 ×2 특수함선(EARTH_RESIST_SP) 등 이미 배수가 적용된 특수함선에는 재적용(중첩) 금지**. (안 그러면 ×10이 되어 밸런스 붕괴.)
