1. Claude Cowork 이전 권장

Claude Cowork은 claude.ai의 Projects 기능에서 협업 워크스페이스로 운영되며, GitHub 직접 연동을 지원합니다.

1Project 생성 + GitHub 연결

  1. claude.ai 로그인 → 좌측 사이드바 Projects → + Create Project
  2. 이름: Destination Earth
  3. Add Knowledge → Connect GitHub 클릭
  4. GitHub OAuth 인증 → 리포지토리 toy80318-sys/destination_E 선택 → Add
  5. 브랜치: main

2Project Instructions 설정

현재 CLAUDE.md 내용을 그대로 Custom Instructions에 복사:

이 폴더는 데스티네이션 어스 웹게임 폴더입니다. 글로벌 스탠다드 기준으로 게임 완성도가 높아지도록 검증·코딩 작업을 진행하며 주기적으로 버그를 수정합니다. 기존의 유사한 웹게임을 참고해 UI 개선 및 게임 밸런스를 조정합니다. ## 핵심 디렉토리 - game.js (16,609줄) — 메인 게임 로직 - js/data/ — 행성·영웅·퀘스트·아이템 데이터 - js/modules/ — 항성지도·경매·코덱스·바·도감 - js/story-quest-engine.js — 시나리오 퀘스트 엔진 - js/story-scenes-pc.js — 컷씬·대화 시스템 - index.html — 진입점 ## 작업 원칙 - 한국어로 응답 - 200줄 넘는 파일은 신중하게 분할 (의존성 깨질 위험) - 새 기능 추가보다 기존 버그 수정 우선 - 변경 시 _GAME_VER · package.json · service-worker.js 동기화 ## 출시 채널 - 웹: GitHub Pages (https://toy80318-sys.github.io/destination_E/) - PC: Electron 빌드 (dist/)

4동기화 정책 확인

✓ 즉시 동기화: Project 설정 → Knowledge → Sync now 클릭으로 수동 강제 갱신.
⚠️ 한도:
  • Project 1개당 Knowledge 파일 한도 약 200,000 토큰 (대형 파일 자동 청크)

2. Antigravity 이전

Antigravity는 Google의 AI 에이전트 IDE로, 워크스페이스 단위로 코드를 클론하여 멀티 에이전트가 동시 작업할 수 있습니다.

1Antigravity 설치 & 가입

  1. antigravity.google 접속 → Google 계정으로 로그인
  2. 데스크톱 클라이언트(Windows/Mac/Linux) 또는 웹 클라이언트 선택
  3. 워크스페이스 생성 시 GitHub 계정 연동 권장

2방법 A — GitHub 클론 (권장)

# Antigravity 메뉴: File → Clone Repository # URL 입력란에 붙여넣기 https://github.com/toy80318-sys/destination_E.git # 또는 Antigravity 터미널에서 직접 클론 git clone https://github.com/toy80318-sys/destination_E.git cd destination_E npm install

2방법 B — 로컬 폴더 직접 열기

# Antigravity 메뉴: File → Open Folder # 경로 선택: /home/user/destinatione # 또는 CLI 에서 antigravity open /home/user/destinatione

3Agent 컨텍스트 설정

Antigravity는 .aiignore, AGENTS.md, CLAUDE.md 등 표준 컨텍스트 파일을 자동 인식합니다.

# AGENTS.md 생성 — Antigravity 에이전트에게 프로젝트 안내 cat > AGENTS.md <<'EOF' # Destination Earth — Agent 안내 ## 프로젝트 개요 한국어 + 영문 지원 우주 무역 RPG 웹게임. - 웹 빌드: index.html + game.js + js/** - PC 빌드: Electron (electron/main.js) ## 빌드 & 실행 - 개발 서버: `python3 -m http.server 8000` 또는 VSCode Live Server - Electron: `npm run electron` - PC 배포 빌드: `npm run dist` ## 테스트 - 통합 테스트 없음 (수동 시뮬레이션) - Node 파서 검증: `node -e "new Function(require('fs').readFileSync('game.js','utf8'))"` ## 코드 스타일 - 한국어 주석 적극 사용 - 함수당 200줄 이하 권장 - 글로벌 함수 + window.* 노출 패턴 EOF

4의존성 설치 & 첫 실행

# Antigravity 워크스페이스 터미널에서 npm install # 웹 빌드 로컬 테스트 python3 -m http.server 8000 # → http://localhost:8000 에서 게임 실행 # Electron PC 빌드 테스트 npm run electron

5멀티 에이전트 활용

Antigravity 의 강점 — 여러 에이전트를 병렬로 작업시킬 수 있습니다.
  • Builder Agent: game.js 분할 / 모듈화 작업
  • Tester Agent: 시나리오 테스트 자동화 작성
  • Localizer Agent: i18n_dict.js 영문 번역 보강
  • Designer Agent: UI 카드 디자인 개선
각 에이전트는 독립 브랜치에서 작업 → PR 자동 생성.

4. 문제 해결 (Troubleshooting)

Q1. Claude Cowork에 GitHub 연결이 실패

  • Pro/Team 플랜이 아닌 경우 GitHub 연동 미지원 → 파일 직접 업로드로 대체
  • 리포지토리가 private인 경우 OAuth scope 재인증
  • 대체: game.js, js/**.js 만 ZIP 으로 묶어 업로드

Q2. 토큰 한도 초과로 컨텍스트 잘림

  • .claudeignore 에 이미지 폴더 모두 추가
  • i18n_dict.js (712 KB) 가 가장 무거움 — 필요 없으면 제외
  • game.js 를 향후 분할하면 부분 로딩 가능

Q3. Antigravity 에서 npm install 실패

# Node 버전 확인 (16 이상 필요) node -v # 캐시 정리 후 재시도 rm -rf node_modules package-lock.json npm cache clean --force npm install

Q4. Electron 빌드가 안 됨

# electron-builder 종속성 별도 설치 npm install --save-dev electron electron-builder # Mac/Linux 빌드 npm run dist # Windows 빌드 (Mac에서 cross-compile) npm run dist:win

Q5. 컷씬·시나리오 컨텍스트가 너무 커서 도구가 느려짐

컷씬 데이터(phase1~6_quests.js)는 총 200KB 이상입니다. 분석할 페이즈만 골라서 Knowledge 에 추가하거나, Doc/DE_시나리오_정리본.md 요약본만 활용하세요.
